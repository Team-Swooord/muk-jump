- 검증 중. 아직 전체 통과 / 심사 제출 가능 상태로 판정하지 않았다.

- 최신 테스트 업로드는 **`20260923-4`**(2026-09-23 13:25 KST, SDK 3.0.1, 검토 필요)이다. 먹점프 운영 보상형·배너 ID를 적용한 디버그 없는 출시 후보이며, 실제 `.ait` 내부를 검사한 파일을 업로드했다. 테스트 화면의 배포 ID 일치와 `푸시를 발송했어요` 응답을 확인했다. 정식 검토 요청·출시는 아직 하지 않았다.
- 앱 정보 화면의 `앱이 승인되었어요`는 등록 정보 승인이다. 위 번들 행의 `검토 필요`와 구분한다. 운영 ID 출시 후보 `ait-build/mukjump.ait`는 2026-09-23 01:19 KST 생성본이다. 광고 발급 후속 예약은 이미 완료·삭제했다.
- 토스 사용자 식별과 기기 내 저장은 구현되어 있다. 기기 변경 시 성장 데이터 복원용 자체 서버는 미구현이다. 게임센터 순위 제출과 성장 저장은 다른 기능이다.

- 서비스 약관 준비와 별도 토스 로그인 구현을 구분한다. 현재 게임 시작은 `AIT.GetUserKeyForGame()`과 게임센터 프로필을 사용하며 `appLogin` 서버 인증은 없다. 콘솔 등록만으로 로그인·동의 수집·저장 복원이 구현된 것으로 판정하지 않는다. 실제 별도 로그인 활성화 전에는 이름 수집의 목적·보유기간과 개인정보 수집·이용 동의, 서버 토큰 교환, 연결 해제 및 삭제 처리, 해당 시 국외 이전 안내를 실제 운영 구성과 맞춰 검증한다. 게임 식별키가 존재한다는 이유로 서비스 약관 준비를 해당 없음 처리하지 않는다.
- IAP, 초대 보상, 웹보드는 제공하지 않는다. 해당 항목은 통과가 아니라 해당 없음이다.

## 이번 수정 및 검증 기록

- 토스 광고 provider를 공통 광고 진행 상태에 연결. 열린 광고의 임의 90초 종료 제거, 웹뷰 정지 시간을 광고 시작 실패 시간에서 제외.
- Android back/home → 종료 확인. 확인 중 중복 종료 요청 차단, 종료 실패 복구, 본인이 걸었던 일시정지만 해제.
- 종료 확인·백그라운드에서 배너 차단.

## 실기기 최종 시나리오

1. 최신 QR 빌드를 Android와 iPhone 토스에서 실행. 첫 화면까지 걸린 시간, 노치/닫기 버튼, 회전, 드래그를 확인.
2. 새 사용자 식별 → 한 판 → 게임오버 저장 → 완전 종료 → 재진입. 고도·시간·먹빛·성장·스킨·게임센터 점수 확인.
3. 설정 BGM/SFX/진동 OFF, OS 무음/진동 OFF, 홈 이동·복귀, 잠금·해제를 각각 확인.
4. 옵션/성장/꾸미기/스킬 팝업/게임/일시정지/게임오버에서 뒤로가기 및 호스트 X 확인. 취소하면 원래 화면과 중지 상태가 유지되어야 함.
5. 공식 테스트 광고로 중간 닫힘, 완주, 중복 클릭, 백그라운드, no-fill을 검증. 운영 광고는 출시에 필요한 최소 노출 확인만 하고 임의 클릭/반복 노출로 수익을 발생시키지 않음.
6. 운영 광고 반영 후 새 출시용 번들로 47·54번을 확인하고, 미확인 항목을 완료 처리하지 않은 상태로 제출 가능 여부 재판정.
