#### 전환 지표 연결 계약

- Unity의 내부 화면은 웹 URL 변경이 아니므로 `mukjump_screen_view`와 `screen_name`을 명시적으로 전달한다.
- 사용자 여정은 `mukjump_run_started` → `mukjump_first_stroke` → `mukjump_run_completed`로 구분한다.
  튜토리얼 저장 완료는 `mukjump_tutorial_completed`, 성장 저장 완료는 `mukjump_growth_completed`다.
- 화면은 `AnalyticsScreen`, 완료/기능 노출은 `AnalyticsImpression`을 사용한다. 게임 이벤트를 광고 클릭으로 보내지 않는다.
- 콘솔 대표 전환은 사용자 정의 **먹점프 정상 플레이 완료**로 설정하고 이벤트를 `mukjump_run_completed`에 직접 연결했다.
  `mukjump_tutorial_completed`와 `mukjump_growth_completed`는 보조 지표로 두었다. 2026-09-23 해당 이벤트 1건씩의
  수신 표시를 확인했지만 콘솔 전환 집계와 같은 사용자의 연속 여정은 아직 확인하지 않았다. 로그인·광고 클릭을 기본 성공으로 대체하지 않는다.
- [공식 이벤트 안내](https://developers-apps-in-toss.toss.im/guide/analytics/logging)에 따라 샌드박스/출시 준비 데이터로
  콘솔 집계를 검증할 수 없으며, 출시 다음 날의 데이터가 필요하다. 코드의 SDK 호출 성공도 콘솔 집계 성공 증거가 아니다.
- [전환 지표 설정](https://developers-apps-in-toss.toss.im/guide/analytics/conversion-metrics)은 컴퓨터 유즈 재연결 후 등록했다.
  콘솔의 `7일 이후 재방문 유저 활성`과 직접 연결된 대표 전환을 확인했다. 사용자 정의 매개변수
  `screen_name`, `score`, `schema_version`, `new_best`, `level`, `growth_level`의 한국어 정의도 저장하고 상세 화면에서 확인했다.
  콘솔은 설정 다음 날부터 표시된다고 안내한다. 실제 지표 수치는 아직 확인하지 않았으며,
  `7일 이후 재방문`을 정확히 7일째의 D7 리텐션으로 바꾸어 표현하지 않는다.
- 개인정보처리방침 준비본에 최소 이용 지표를 추가했다. 공개 게시본과 콘솔 링크의 최신 반영은 별도 남아 있다.

2. 새 사용자 식별 → 한 판 → 게임오버 저장 → 완전 종료 → 재진입. 고도·시간·먹빛·성장·스킨·게임센터 점수 확인.
3. 설정 BGM/SFX/진동 OFF, OS 무음/진동 OFF, 홈 이동·복귀, 잠금·해제를 각각 확인.
4. 옵션/성장/꾸미기/스킬 팝업/게임/일시정지/게임오버에서 뒤로가기 및 호스트 X 확인. 취소하면 원래 화면과 중지 상태가 유지되어야 함.
5. 공식 테스트 광고로 중간 닫힘, 완주, 중복 클릭, 백그라운드, no-fill을 검증. 운영 광고는 출시에 필요한 최소 노출 확인만 하고 임의 클릭/반복 노출로 수익을 발생시키지 않음.
6. 운영 광고 반영 후 새 출시용 번들로 47·54번을 확인하고, 미확인 항목을 완료 처리하지 않은 상태로 제출 가능 여부 재판정.
