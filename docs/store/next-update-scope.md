## 포함

- 토스에도 일회성 영구 광고 제거와 금색 먹. 각 스토어의 검증된 구매 권한만 사용하며 플랫폼 간 자동 공유·새 서버·새 로그인은 없다.

- 구매자는 배너·전면·보상형 광고 모두 제거. 부활은 광고 없이 기존 자격과 한 판 1회 한도를 유지한다.
