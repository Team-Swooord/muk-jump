# 바로 다음 업데이트 범위

2026-09-28 사용자 지정 범위. 현재 심사 제출된 iOS 1.0.3(44)와 별개의 다음 업데이트 준비이며, 새 버전·빌드 번호는 아직 지정하지 않았다.

## 포함

- 황금먹 패키지 화면 개선: 혜택 문구·실제 스토어 가격·구매 버튼 가독성, 은은한 금색 그라데이션, 설정의 구입 복원.
- 팝업은 별도 닫기/X 없이 바깥 영역 탭으로 닫기. 내부 터치·스크롤·밖으로 끌기는 닫지 않으며 닫은 입력이 게임으로 전달되지 않게 한다. 거래 안전 잠금은 유지한다.
- 토스에도 일회성 영구 광고 제거와 금색 먹. 각 스토어의 검증된 구매 권한만 사용하며 플랫폼 간 자동 공유·새 서버·새 로그인은 없다.
- iOS·토스 전면광고: 게임 3판 종료마다, 마지막 전면/부활 광고 종료 뒤 최소 120초. 구매자·보유 확인 중·부활 광고를 사용한 판·광고 미준비는 제외하고 입력·음향 복귀를 확인한다.
- 구매자는 배너·전면·보상형 광고 모두 제거. 부활은 광고 없이 기존 자격과 한 판 1회 한도를 유지한다.

## 보류 및 보존

- 가운데 먹과 스킨·착지·붓·분신의 네 갈래 꾸미기 전면 개편.
- 까치 둥지·댓잎·먹 올챙이 3종의 노출·해금·장착·플레이 표시.
- 이번에 포함하도록 지정되지 않은 성장 화면의 최대 그리기 길이 비교.
- 기존 스킨 목록·ID·보유·착용·계정·기록은 유지한다. 새 외형의 기존 저장값도 삭제하지 않고 기본 외형으로 표시한다. 보류 코드·원화와 테스트는 향후 재개를 위해 보존한다.

## 제출 전 남은 단계

- 콘솔 작업은 사용자 재개 지시 전까지 보류한다. 반복 출시 확인 예약도 사용자 요청으로 중지했다.
- 토스 비소모성 상품/SKU, 토스 전면 광고 그룹, iOS AdMob 전면 광고 단위의 실제 등록·연결이 필요하다. 가짜 운영 값을 넣지 않는다.
- 실제 StoreKit·토스 결제/복원/권한 회수, 광고 복귀 입력·음향, 토스 구배포→새배포 기록·보유·착용 보존을 실기기에서 확인해야 한다.
- 등록과 필수 검증 후 동일 승인 범위로 양 플랫폼 정상 빌드·서명·패키지 검증을 수행한다. 콘솔 재개 전 업로드·심사·공개하지 않는다.
- 로컬 테스트 성공은 실결제·운영 광고 연결·전체 출시 완료를 뜻하지 않는다. 현재 심사 44를 취소하거나 최신 main 전체를 예전 승인으로 제출하지 않는다.

## 로컬 준비 확인

관련 검사 155개는 각 검사의 최종 실행 결과가 모두 통과했다. 새 출시 경계 6개는 기존 의상 ID·금색 유지, 보류 외형 자동 지급/장착/렌더링 차단, 기존 보유/선택 저장 보존과 구 저장 이관을 검사한다. 실제 Play 검사 1개는 320×568·390×844 × 한국어/영어/일본어의 기존 꾸미기 화면 6장을 촬영하고 금색 착용·전체 보기 전환·로비 복귀를 실제 UI Raycast로 확인했다. 메모리 공급자를 사용한 Editor 검사이며 실제 결제나 모바일 터치 검증은 아니다.

iOS 61개·WebGL 57개 관리 어셈블리 컴파일과 공식 빌더 씬 생성을 완료했다. 마지막 감사는 Main 씬 로드·iOS·Play 종료·컴파일/업데이트 종료·소스 일치·씬 clean·누락 스크립트 0·Player 안전 문제 0이다. 재컴파일 명령 내부 결과는 `up_to_date`, `failed=false`다.

편집기 연결 도구의 포트 충돌/응답 실패로 Unity 기본 Test Runner 및 같은 빌더·감사 진입점(`NextUpdatePreparation`)을 사용했다. 패키지·인증·Player 원격 제어 설정은 변경하지 않았다. 첫 성장 문구 기대값 실패, 다른 팝업 Canvas를 선택한 검사 실패, Editor 창 크기로 Raycast하던 검사 실패와 수정 후 성공을 함께 보존한다. Raycast는 실제 게임 Update에서 실행하도록 검사 도구만 보완했다. 최종 검증 실행은 정상 종료했으며 다른 프로젝트 Unity는 건드리지 않았다.
