# 작업 완료 시 커밋 정책

2026-09-10 사용자 지시: 이후 작업은 완료하고 검증한 시점에 기능 단위로 즉시 커밋한다.
커밋 여부를 매번 다시 묻지 않는다.

- Conventional Commits 형식과 한국어 설명을 사용한다.
- 커밋 전 전체 Git 상태를 확인하되, 해당 작업의 파일만 명시적으로 stage한다.
- 다른 작업자의 미커밋 변경과 기존 스테이징을 섞지 않는다. `git add -A`, `git add .`은 금지한다.
- Push와 PR/merge는 사용자가 요청하거나 승인한 범위에서 수행한다.
- TestFlight 요청 시 승인된 최신 변경을 main에 반영한 후 기존 iOS 생성 출력과 해당
  DerivedData를 정확히 확인·삭제하고 클린 빌드한다. 원본 에셋·소스·Archive는 삭제하지 않는다.
