# NAN 2026 AI 활용 기술 문서

## 프로젝트 요약

- 게임: 먹점프 (MukJump)
- 팀: 최연소밴드 - 김승연, 최성빈
- 개발 기간: 2026.07.20 - 2026.08.07 (19일, 약 3주)
- Git 기록: 310개 커밋
- AI 활용 로그: 224건

먹점프는 런타임에서 외부 AI API를 호출하는 게임이 아니라, 기획, 코드, 아트, 사운드,
밸런스, QA, 문서화 전 공정에 AI를 상시 활용해 완성한 AI 네이티브 제작 프로젝트다.
팀원은 AI가 만든 초안을 그대로 사용하지 않고 최종 선택, 수정, 통합, 실기기 검증을
직접 담당했다.

## 1. 활용 원칙

1. **전 공정 활용**: 아이디어 비교부터 제출 문서까지 AI를 반복 제작 파트너로 사용했다.
2. **사람의 최종 결정**: 기획 의도, 모바일 가독성, 물리 일관성, 게임성, 성능,
   라이선스를 팀원이 최종 판단했다.
3. **추적 가능성**: 도구, 목적, 프롬프트, 결과물, 사람의 수정, 검증을
   `docs/ai-usage-log.md`에 224건 기록했다.
4. **실행 독립성**: 제출 빌드는 API 키와 네트워크 없이 완전히 동작한다.
5. **원본 존중**: 참고 자료는 리듬과 정보 위계만 분석하고 로고, 문구, 정확한 구도를
   복제하지 않았다.

## 2. 사용 도구

- Claude / Claude Code: 초기 콘셉트, 기획 문서화, 자동 점프와 드로잉 발판의 초기 구현.
- OpenAI Codex: Unity 기능 구현, 리팩터링, 아키텍처 분리, 버그 분석, 회귀 테스트,
  모바일 UI 보정, Git과 문서 동기화.
- ChatGPT / OpenAI ImageGen: 먹방울 캐릭터, 아이템, 용과 해태, 수채화 배경,
  성장 나무 UI 시안과 스프라이트 제작.
- Suno v4.5: 가야금, 대금, 장구 중심의 무보컬 반복 BGM 제작.
- Pillow / AVFoundation: 크로마 제거, 알파와 크기 정규화, 참고 영상 프레임 분석.
- Unity Test Framework / Bee / Roslyn: 기능 회귀, 런타임과 에디터 정적 컴파일,
  오류 로그 검증.
- Git / ripgrep / jscpd / Node.js: 변경 추적, 코드 감사, 중복 탐지, 결정론 밸런스 시뮬레이션.

## 3. AI 적용 흐름

1. 팀원이 목표, 제약, 참고 이미지와 완료 조건을 제시한다.
2. AI가 기획 대안, 코드 변경안, 이미지 또는 사운드 프롬프트를 만든다.
3. 팀원이 스타일, 밸런스, 가독성, 저작권과 게임성을 검토한다.
4. 선택한 결과만 Unity 코드와 에셋, 씬 빌더에 통합한다.
5. 정적 컴파일, 회귀 테스트, Game View, 실제 모바일 기기에서 검증한다.
6. 채택 또는 폐기 이유를 AI 로그와 기능 단위 커밋으로 남긴다.

## 4. 대표 활용 사례

### 코어 게임 구현

자동 점프, 터치 스트로크, Chaikin 스무딩, EdgeCollider2D 발판, 추락 복귀,
다중 분신 카메라, 먹 총량과 오래된 획 소멸을 AI와 함께 설계하고 코드로 구현했다.

### 수묵 아트 제작

`검정과 한지색 중심, 굵은 먹 외곽선, 단순하고 귀엽게, 텍스트와 3D 표현 없음`처럼
제약이 분명한 프롬프트를 사용했다. 팀원이 생성 결과를 비교하고 크로마 제거, 투명화,
크기, 기준점, 프레임 일관성을 직접 보정했다.

### UI와 VFX

모바일 Safe Area, 고정 글자 크기, 충분한 터치 영역, 팝업 DIM과 입력 차단을 AI가
코드 계약으로 정리했다. 참고 연출은 시간 구조만 분석하고 먹색, 한지색, 절제된 금빛의
먹점프 스타일로 다시 제작했다.

### 저장과 예외 QA

손상 JSON, 미래 버전, 부분 쓰기, 백업 실패, 복구 버튼 연속 입력처럼 사람이 놓치기
쉬운 조합을 AI 멀티에이전트가 감사했다. 수정 뒤 해당 경계를 회귀 테스트로 고정했다.

### 밸런스 분석

결정론적 다중 seed 시뮬레이션으로 장애물 간격과 성장 보상을 비교했다. 이 결과는 실제
사용자 로그나 자동 플레이 학습이 아니라 확률 입력 기반 가설임을 명시하고, 최종 수치는
사람의 플레이 테스트로 결정했다.

## 5. 대표 프롬프트 유형

- 기능 구현형: `기존 물리와 저장 규칙은 유지하고 지정 기능만 추가하라.`
- 스타일 제약형: `검정과 한지색, 굵은 먹 외곽선, 단순하고 귀엽게. 텍스트와 3D 없음.`
- 레퍼런스 변환형: `원본은 리듬과 정보 위계만 참고하고 먹점프 팔레트로 재해석하라.`
- 품질 감사형: `취약점, 불필요 코드, 성능 위험을 찾고 회귀 테스트로 고정하라.`
- 밸런스 분석형: `결정론적 다중 seed로 비교하되 실제 사용자 데이터처럼 과장하지 말라.`

## 6. 사람의 개입

- 생성 이미지 비교, 채택과 폐기, 투명화와 프레임 보정.
- 실제 플레이 감각과 물리 수치, 장애물 밀도와 성장 밸런스 조정.
- Android와 iPhone 세로 화면의 Safe Area, 글자, 터치 영역 검수.
- AI가 요구를 잘못 이해했을 때 기획을 다시 정의하고 구현 범위를 축소.
- 외부 에셋 출처와 라이선스 확인.
- 기능 단위 커밋 검토와 최종 승인.

## 7. 검증과 재현성

- Unity 6000.3.10f1 Bee 응답 파일 기반 Runtime / Editor 정적 컴파일.
- Unity Test Framework 기반 저장, 성장, 물리, 카메라, UI 경계 회귀.
- 540x960 Game View, Android 20:9, iPhone 19.5:9 Safe Area 계약.
- 최근 결실 패시브 대상 13개 테스트 13/13 통과.
- 프로젝트 씬은 수동 편집이 아니라 에디터 빌더로 재생성.
- 게임 규칙 난수와 연출 난수를 분리해 VFX 변경이 난이도를 바꾸지 않도록 구성.

## 8. 안전과 권리

- 제출 빌드는 외부 AI API, 로그인, 서버, 개인정보 수집을 사용하지 않는다.
- 원격 AI가 없어도 `SketchToInkService`와 `FallbackInkStyle`의 로컬 갈필이 동작한다.
- `Inkdrop Ascent.mp3`는 팀 Suno Pro 계정으로 생성했다.
- 붓 효과음은 Freesound CC0, 사망과 게임오버 효과음은 Pixabay Content License다.
- Unity 공식 패키지는 Unity Companion License를 따른다.
- 폰트와 Pngtree 붓획은 제출 전 재배포 범위와 라이선스 증빙을 최종 확인한다.
