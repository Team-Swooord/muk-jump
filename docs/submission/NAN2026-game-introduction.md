# NAN 2026 게임 소개 및 설명 문서

## 기본 정보

- 게임명: 먹점프 (MukJump)
- 팀명: 최연소밴드
- 팀원: 김승연, 최성빈
- 개발 기간: 2026.07.20 - 2026.08.07 (19일, 약 3주)
- 장르: 세로형 캐주얼 드로잉 클라이밍
- 플랫폼: Android 세로 화면
- 엔진: Unity 6000.3.10f1, URP 2D
- 공개 저장소: https://github.com/Team-Swooord/muk-jump

> 선 하나가 발판이 되고, 발판 하나가 그림이 된다.

## 1. 게임 개요

먹점프는 자동으로 뛰는 먹방울 캐릭터를 직접 조종하는 대신, 화면에 붓선을 그려
발판을 만들고 다음 점프의 방향과 높이를 설계하는 모바일 클라이밍 게임이다.
한지, 먹 번짐, 갈필 질감을 사용해 플레이어가 남긴 경로 자체가 한 폭의 산수화처럼
완성된다.

- 목표: 살아 있는 먹방울을 지키며 최고 고도를 갱신한다.
- 한 판 길이: 약 1-3분의 빠른 반복 도전.
- 핵심 순환: 관찰 - 한 획 - 자동 점프 - 위험 대응 - 상승 - 재도전.
- 종료 조건: 본체와 모든 분신이 사망하면 게임오버.
- 기록: 한 판에서 도달한 최고 고도.

## 2. 핵심 재미

1. **캐릭터가 아니라 길을 조작한다.** 캐릭터는 약 1초마다 자동 점프하고,
   발판의 위치, 기울기, 길이가 다음 궤적을 결정한다.
2. **그린 선이 실제 물리가 된다.** 손가락 궤적은 부드럽게 보정된 뒤 갈필 질감과
   충돌 판정을 가진 실제 발판이 된다.
3. **제한된 먹을 순환시킨다.** 기본 최대 먹 용량은 4.8m다. 새 선을 그리면 가장
   오래된 먹부터 마르며 시각과 충돌 판정이 함께 사라진다.
4. **먹떼로 생존한다.** 먹분신은 개별 체력을 가진다. 일부가 죽어도 한 마리만
   살아 있으면 플레이가 계속된다.
5. **수묵 세계가 고도에 따라 변한다.** 산길, 바람 능선, 먹비 계곡, 검은 절벽을
   지나 1000m 이후에는 수묵과 우주가 섞인 무한 구간으로 이어진다.

## 3. 플레이 방법

- 로비에서 `시작`을 누른다.
- 플레이 영역을 누른 채 드래그하고 손가락을 떼어 발판을 만든다.
- 이동과 점프 버튼은 없다. 캐릭터는 자동으로 점프한다.
- 발판의 기울기는 좌우 방향, 길이는 점프 힘과 높이에 영향을 준다.
- 우측 상단 버튼으로 일시정지한다.
- 결과 두루마리를 확인한 뒤 다시 시작한다.

최초 접속 시 게임 화면에서 5단계 튜토리얼이 한 번 실행된다. 튜토리얼이 열려 있는
동안 월드, 물리, 기록 시간은 멈춰 있으며 그리기, 발판, 먹 게이지, 장애물, 아이템을
차례로 익힌다.

## 4. 먹, 체력, 카메라

- 기본 최대 먹 용량은 4.8m이며 영구 성장으로 최대 20.4m까지 확장할 수 있다.
- 게이지는 현재 화면에 남아 있는 먹선 총량을 나타낸다.
- 발판은 시간이 지나면 처음 그린 쪽부터 마르고, 사라진 양만큼 게이지가 회복된다.
- 본체 기본 체력은 1칸이며 선택 성장으로 최대 4칸이 된다.
- 분신 기본 체력은 1칸이며 결실 성장 선택 시 2칸이 된다.
- 체력은 각 캐릭터 머리 위의 독립된 칸으로 표시된다.
- 카메라는 본체 고정이 아니라 가장 높은 생존 먹방울과 먹떼 분포를 고려해 추적한다.
- 화면 아래로 떨어진 개체는 체력 1칸을 소모하고, 살아 있으면 화면 안으로 복귀한다.

## 5. 아이템과 위험 요소

### 아이템 4종

- 먹물방울: 살아 있는 먹떼 전체를 50m 상승시킨다.
- 황금 붓: 8초 동안 최대 먹 용량에 따른 오래된 획 퇴출을 보류한다.
- 먹 방어막: 장애물 피해 또는 추락을 1회 막는다.
- 먹분신: 획득한 캐릭터 옆에 분신을 1마리 만든다. 선택 성장 시 한 번에 2마리다.

### 장애물과 환경

- 30m까지는 공격 장애물이 없는 학습 구간이다.
- 이동 먹가시, 낙묵석, 어린 동양 용, 벽을 따라 내려오는 먹해태가 등장한다.
- 천천히 바뀌는 횡풍과 드물게 발생하는 상승기류가 점프 궤적을 흔든다.
- 좌우 경계에 부딪히면 화면 안쪽으로 강하게 튕겨 무한 벽타기를 막는다.

## 6. 영구 성장

정상 게임오버 시 누적 고도에 따라 단일 재화 `먹빛`을 얻는다. 성장 나무는 생존,
도약, 먹 운용 세 계보로 구성되며 총 39개 노드가 있다. 각 계보에서는 세 줄기 중
한 줄기만 활성화해 자신의 빌드를 정한다. 구매 기록은 보존되고 활성 줄기는 무료로
교체할 수 있다.

- 생존 결실: 분신 체력 +1, 본체 1회 부활과 50m 상승, 먹분신 생성 +1.
- 도약 결실: 점프 아이템 종료 방어막, 좌우 벽 자동 점프, 매 자동점프 2단 도약.
- 먹 운용 결실: 최대 먹 용량 2배, 황금 붓 획득 시 방어막, 먹 회복 속도 증가.

플레이 중 무작위 증강 카드나 도감은 사용하지 않는다. 한 판의 조작 숙련과 장기적인
빌드 선택에 집중한 구조다.

## 7. 실행 방법

### Android APK

1. 제출 APK를 Android 7.1(API 25) 이상 ARM64 기기에 내려받는다.
2. 필요하면 `알 수 없는 앱 설치 허용`을 활성화한다.
3. APK를 설치하고 먹점프를 실행한다.
4. 회원가입, 로그인, API 키, 네트워크 연결 없이 바로 플레이한다.

### Unity 프로젝트

1. `https://github.com/Team-Swooord/muk-jump`를 클론한다.
2. Unity Hub에서 Unity 6000.3.10f1로 저장소 루트를 연다.
3. `Assets/Scenes/Main.unity`를 열고 Game View를 9:16으로 설정한다.
4. Play를 누른다.
5. 씬 재생성이 필요할 때만 `MukJump > Build Main Scene`을 실행한다.

## 8. AI 네이티브 제작

먹점프는 기획 구체화, 코드 작성과 리팩터링, 수묵 아트와 사운드 생성, 밸런스 분석,
QA 설계, 제출 문서화까지 전 개발 공정에 AI를 상시 활용했다. 최종 기획 판단, 산출물
선별, 코드 통합, 실기기 테스트는 두 팀원이 직접 수행했다. 제출 빌드는 원격 AI API나
API 키에 의존하지 않으며 오프라인에서도 완전히 동작한다.
