# NAN 2026 팀 소개 및 역할 문서

## 팀 정보

- 팀명: 최연소밴드
- 팀원: 김승연, 최성빈
- 개발 기간: 2026.07.20 - 2026.08.07 (19일, 약 3주)
- 프로젝트: 먹점프 (MukJump)
- 공개 저장소: https://github.com/Team-Swooord/muk-jump

최연소밴드는 UI/UX와 게임·기획의 책임을 명확히 나누고, 통합 단계에서는 서로의
결과물을 직접 플레이하며 검수한 2인 팀이다. 약 3주의 짧은 개발 기간 동안 기획,
코드, 아트, 사운드, 테스트, 문서화 전 공정에 AI를 상시 활용해 반복 속도를 높였다.

## 1. 김승연 - UI/UX·아트 디렉션

### 주 담당

- 로비, 옵션, 튜토리얼, 일시정지, 게임오버, 영구 성장 화면의 UI/UX.
- Android와 iPhone 세로 화면 Safe Area, 글자 가독성, 버튼 터치 영역 검수.
- 한지, 먹 번짐, 갈필, 낙관색을 사용한 수묵 아트 방향 설정.
- ChatGPT와 ImageGen 프롬프트 작성, 생성 이미지 비교와 최종 에셋 선정.
- 크로마 제거, 투명화, 크기와 기준점 정규화, UI와 VFX 통합 피드백.
- 실기기 UI 테스트와 제출 문서, 시연 동선 구성.

### 목표

작은 모바일 화면에서도 정보가 즉시 읽히고, 모든 버튼과 팝업이 먹점프의 수묵 세계에
자연스럽게 녹아들도록 만드는 것을 담당했다.

## 2. 최성빈 - 게임·기획·밸런스

### 주 담당

- 자동 점프와 드로잉 발판의 코어 게임 규칙과 플레이 흐름 설계.
- 먹 총량, 오래된 획 소멸, 분신 생존, 체력, 카메라 시스템 기획과 구현 검수.
- 아이템, 장애물, 날씨, 맵 구간, 영구 성장 39노드의 콘텐츠와 밸런스.
- Unity 게임 코드, 상태 전이, 물리와 오브젝트 풀링의 통합 검토.
- 회귀 테스트, 예외 경계, 기계 번역과 플레이 밸런스 QA.
- 빌드 실행 흐름과 게임 설명의 기술 검수.

### 목표

캐릭터를 직접 움직이지 않아도 한 획의 선택이 곧 위험과 보상이 되도록 게임 규칙과
난이도 곡선을 만드는 것을 담당했다.

## 3. 공동 책임

- 프로젝트 방향, 우선순위, 해커톤 제출 범위 결정.
- UI 입력과 게임 상태가 만나는 지점의 상호 검수.
- 실제 기기 플레이 피드백을 즉시 다음 작업에 반영.
- AI 결과의 채택, 수정, 폐기 결정과 외부 에셋 라이선스 확인.
- README, 게임 기획, AI 활용 로그, 제출 문서 최신화.
- Git 변경 검토와 최종 main 통합.

## 4. AI 네이티브 협업 방식

1. 팀원이 문제와 완료 조건을 정한다.
2. AI가 기획 대안, 코드 초안, 이미지·사운드 프롬프트를 만든다.
3. 김승연이 UI·아트·모바일 경험을, 최성빈이 규칙·물리·밸런스를 검수한다.
4. 선택한 결과만 하나의 Unity main 프로젝트에 통합한다.
5. 정적 컴파일, 회귀 테스트, 실기기 플레이 후 다시 수정한다.
6. 도구와 프롬프트, 사람의 판단을 AI 활용 로그와 커밋으로 남긴다.

## 5. 개발 결과

- 19일 동안 310개 기능 단위 커밋.
- AI 활용 작업 224건 기록.
- 자동 점프와 한 획 발판이라는 독자적인 조작 구조 완성.
- 캐릭터, 아이템, 장애물, 배경, UI를 하나의 수묵 스타일로 통합.
- 다중 분신 카메라, 개별 체력, 먹 총량, 39노드 선택 성장 구현.
- API 키와 네트워크 없이 실행되는 Android 빌드 구조.

## 6. 팀의 강점

시각적 완성도와 게임 규칙을 분리해 책임지되, 매 통합 단계에서 서로의 결과를 직접
플레이했다. AI를 단순 자동 생성기로 사용하지 않고 아이디어 비교, 구현, 실패 경계 감사,
실기기 피드백 반영을 빠르게 반복하는 세 번째 협업자처럼 활용했다. 그 결과 짧은 기간에도
`그린 선이 곧 물리 발판이고 수묵화가 되는 경험`을 하나의 일관된 게임으로 완성했다.
