# 먹점프 계정 및 데이터 삭제 안내

## 앱 안에서 삭제

1. 먹점프 메인 화면에서 `설정`을 엽니다.
2. `계정`을 선택합니다.
3. `계정 삭제`를 누릅니다.
4. 삭제되는 항목을 확인한 뒤 같은 버튼을 한 번 더 눌러 확정합니다.

삭제 요청이 성공하면 즉시 로그아웃되고 해당 계정으로 다시 로그인할 수 없습니다. 뒤끝
서버의 최종 삭제 작업은 정시 단위로 처리되어 최대 1시간이 걸릴 수 있습니다.

## 삭제되는 항목

- 뒤끝 사용자 계정과 Google·Apple 로그인 연결
- 최고 고도 리더보드 기록
- 최고 고도, 먹빛, 성장 노드, 활성 결실, 튜토리얼과 옵션을 포함한 서버 게임 데이터
- 삭제를 실행한 현재 기기의 로컬 최고 기록, 성장 원본·백업·격리본, 동기화 보류 작업
- Apple 로그인 계정의 경우 재인증 후 Apple 토큰 승인 철회

광고 사업자가 독립적으로 처리하는 집계·부정 이용 방지 기록과 법률상 보존 의무가 있는
기록은 각 사업자의 정책에 따라 일정 기간 보관될 수 있습니다.

## 앱을 열 수 없는 경우

`cysbandcs@gmail.com`으로 제목을 `먹점프 계정 삭제 요청`으로 작성해 문의해 주세요.
문의에는 사용한 로그인 방식(게스트·Google·Apple), 계정 화면에 표시되는 `지원 코드`,
계정에 접근할 수 없는 사유를 적어 주세요. 최고 고도 같은 공개·추측 가능한 게임 정보만으로
본인을 확인하지 않습니다. 비밀번호, Apple·Google 인증 코드, 로그인 토큰은 요구하지
않습니다.

이메일만으로 계정을 안전하게 식별할 수 없으면 삭제를 바로 실행하지 않고 추가 확인을
요청할 수 있습니다. 처리 결과는 요청에 사용한 이메일로 알립니다. 스토어 제출 전에는
뒤끝 콘솔의 공식 회원 탈퇴 웹 링크를 생성하고, 비로그인 브라우저에서 동작을 확인한 뒤
이 안내 페이지와 각 스토어의 외부 삭제 URL에 연결합니다.
