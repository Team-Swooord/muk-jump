# 먹점프 앱인토스 개인정보처리방침

시행일: 공개 게시일

먹점프 앱인토스판의 개인정보 처리자는 최성빈(최연소밴드, CYSBand)입니다.
개인정보 관련 문의는 cysbandcs@gmail.com으로 보내실 수 있습니다.
이 방침은 토스 앱 안에서 제공되는 먹점프에 적용됩니다.

## 1. 처리 항목과 목적

| 구분 | 항목 | 목적 |
| --- | --- | --- |
| 게임 사용자 확인 | 토스가 제공하는 게임별 사용자 식별자, 사용자 확인 결과 | 사용자 구분, 다른 사용자의 로컬 기록과 혼동 방지, 순위 기능 제공 |
| 게임 이용 | 최고 고도, 플레이 기록, 먹빛, 성장 단계, 스킨 해금·착용, 튜토리얼 진행, 설정, 저장 버전과 복구 정보 | 게임 진행 저장, 성장·꾸미기 기능, 중복 정산 방지와 기록 복구 |
| 순위 | 사용자 식별자와 게임센터에 제출하는 점수 | 토스 게임센터 순위 제공 |
| 고객지원 | 이용자가 직접 제공한 이메일 주소, 문의 내용과 첨부 자료 | 문의 답변, 오류 확인과 권리 행사 처리 |

현재 게임 사용자 확인은 게임 전용 식별 기능을 사용하며, 운영자가 별도 토스 로그인을 통해
실명, 이메일, 전화번호, 생년월일 또는 CI를 수집하는 기능은 제공하지 않습니다.
토스 로그인 기능을 도입하여 추가 정보를 받는 경우에는 적용 전에 처리 항목과 목적,
보유기간을 안내하고 필요한 동의를 별도로 받습니다.

현재 앱인토스판은 Apple·Google 로그인, 뒤끝 계정 서버, 네이티브 AdMob SDK 또는
Firebase Analytics 네이티브 모듈을 사용하지 않습니다. 토스 플랫폼의 분석·광고 처리는
아래 외부 서비스 설명을 따릅니다.

## 2. 저장 위치와 보유기간

- 게임 사용자 확인에 필요한 로컬 정보와 성장·먹빛·스킨·설정은 이용 중인 기기의 저장
  공간에 보관됩니다. 해당 저장 정보가 삭제될 때까지 유지되며, 저장 공간 삭제나 기기 변경
  후 자동 복원은 현재 제공하지 않습니다.
- 게임센터에 제출한 기록은 토스의 게임센터에서 관리합니다. 표시·보관과 삭제 절차는
  토스의 관련 정책을 따르며 운영자는 문의를 받으면 처리 가능한 범위를 안내합니다.
- 고객지원 기록은 답변 완료 후 90일 동안 보관합니다. 분쟁 처리 또는 법령상 보존 의무가
  있으면 해당 목적에 필요한 최소 항목을 분리하여 필요한 기간에만 보관합니다.

운영자가 보관하는 정보는 보유기간이 끝나거나 처리 목적을 달성하면 지체 없이 삭제합니다.
전자 파일은 복구하기 어려운 방법으로 파기하고 종이 자료는 분쇄 또는 소각합니다.

## 3. 토스 플랫폼과 광고

주식회사 비바리퍼블리카는 앱인토스 플랫폼, 게임 사용자 식별, 게임센터와 광고 기능을
제공합니다. 사용자가 서비스를 이용할 때 해당 기능에 필요한 정보가 토스 플랫폼을 통해
처리됩니다. 게임센터의 닉네임·프로필·점수·순위는 해당 기능의 안내에 따라 다른 이용자에게
표시될 수 있습니다.

광고 요청과 표시 과정에서 토스 및 광고 제공자는 광고 제공·성과 집계·부정 이용 방지를
위해 기기와 접속 기술 정보, 광고 요청·표시·시청 완료 등의 정보를 처리할 수 있습니다.
상세 항목, 제공받는 자, 보유기간과 이용자 선택은 실제 광고 화면과 토스의 개인정보 안내를
따릅니다. 보상형 광고는 이용자가 선택한 경우에 재생하며, 시청하지 않아도 게임을 계속
이용할 수 있습니다.

운영자는 개인정보를 판매하지 않습니다. 운영자가 새로운 처리위탁, 제3자 제공 또는 국외
이전을 도입하는 경우에는 적용 전에 대상·목적·항목·기간을 안내하고 법령상 필요한 절차를
진행합니다. 현재 별도 토스 로그인으로 받은 개인정보를 운영자의 해외 클라우드 서버에
저장하는 기능은 없습니다.

토스의 개인정보 처리에 관한 안내: https://toss.im/privacy-policy

## 4. 이용자 권리와 문의

이용자는 개인정보 열람·정정·삭제·처리정지 및 동의 철회를 요청할 수 있습니다.
운영자는 본인 또는 적법한 대리인임을 확인한 후 관계 법령에 따라 처리 결과를 안내합니다.
법령에 따라 요청이 제한되는 경우에는 그 사유를 안내합니다.

- 문의처: cysbandcs@gmail.com
- 개인정보 담당: 최성빈, 최연소밴드(CYSBand)

문의 시 토스 비밀번호, 인증번호, 원문 인증 토큰은 보내지 마세요. 운영자는 이를 요구하지
않습니다. 기기 내 정보와 토스 게임센터에 보관된 정보는 저장 위치가 달라 하나의 삭제
요청으로 동시에 처리되지 않을 수 있으며, 요청을 받으면 필요한 절차를 안내합니다.

## 5. 안전조치와 방침 변경

운영자는 개인정보 접근 권한을 필요한 범위로 제한하고, 개인정보가 전송되는 서비스 연결에
암호화 통신을 사용하며, 불필요한 개인정보를 로그에 남기지 않도록 관리합니다.
추가 개인정보 수집이나 저장 방식 변경이 있는 경우 변경 내용과 적용일을 사전에 안내하고,
별도 동의가 필요한 처리에는 동의를 받습니다.
