# 먹점프 개인정보처리방침

시행일: 2026년 8월 26일

먹점프 개발팀(CYSBand, 이하 “개발팀”)은 게임 서비스 제공에 필요한 최소한의 정보만
처리합니다. 문의처는 `cysbandcs@gmail.com`입니다.

## 1. 처리하는 정보

### 계정과 게임 저장

- 게스트·Google 로그인, iOS의 Apple 로그인으로 생성되는 뒤끝(BACKND) 사용자 식별자와
  로그인 유형
- 소셜 로그인 제공자가 인증 과정에서 처리하는 이름, 이메일 주소, 사용자 ID 등의 계정
  식별 정보. Google 로그인 SDK는 계정 상태에 따라 전화번호와 기기·이용·대략적 위치
  정보를 처리할 수 있지만 게임은 전화번호를 읽거나 표시하지 않습니다. 개발팀은
  Google·Apple 비밀번호를 받거나 저장하지 않습니다.
- 최고 고도, 먹빛, 성장 노드와 활성 결실, 음량, 튜토리얼 완료 상태, 저장 버전,
  동기화 시각과 중복 처리를 막기 위한 작업 식별자
- 앱 안에서 만든 로컬 게스트 식별자

로그인하지 않거나 네트워크가 없어도 게임은 기기 저장 데이터로 동작합니다. 소셜 로그인은
선택 사항입니다.

뒤끝 SDK의 추가 요청 로그 저장과 IP 기반 국가·도시·지역 자동 조회 기능은 사용하지
않습니다. 서버 요청을 처리하는 과정에서 통신에 필요한 IP 주소와 접속 기술 정보가 처리될
수는 있습니다.

### 광고와 기술 정보

Google Mobile Ads SDK는 광고 제공·집계·부정 이용 방지를 위해 IP 주소로 추정한 대략적
위치, 기기·광고 식별자, 앱 실행과 광고 조회·탭 같은 제품 상호작용, SDK 성능·진단 정보를
자동 처리할 수 있습니다. 먹점프 1.0은 모든 Google 광고 요청을 비맞춤형(`npa=1`)으로
전송하고 iOS App Tracking Transparency 권한을 요청하지 않습니다. 비맞춤형 광고도 빈도
제한과 집계 보고를 위해 기기 식별자를 사용할 수 있습니다.

Google UMP 동의 화면이 필요한 지역에서는 동의 상태를 확인한 뒤에만 광고를 요청하며,
설정의 `광고 개인정보`에서 선택 화면을 다시 열 수 있습니다.

Apps in Toss 버전에서는 토스의 공식 게임·광고 API가 해당 플랫폼 정책에 따라 필요한
식별자와 이용 정보를 처리할 수 있습니다.

### 고객지원

사용자가 이메일로 문의하면 이메일 주소와 문의 내용, 첨부 파일을 답변 및 분쟁 대응에
필요한 기간 동안 처리합니다. 문의는 선택 사항이며 게임의 기본 기능이 아닙니다.

## 2. 이용 목적

- 계정 생성·로그인·기기 간 게임 진행 동기화
- 최고 고도 리더보드 제공과 중복 정산 방지
- 선택형 광고 제공, 광고 빈도 제한, 부정 광고 트래픽 방지
- 저장 오류·충돌·성능 문제 진단과 고객 문의 처리

## 3. 외부 처리 업체

| 업체 | 목적 | 처리 가능 정보 |
|---|---|---|
| 뒤끝(BACKND) | 로그인, 클라우드 저장, 리더보드, 탈퇴 | 사용자 ID, 게임 진행, 접속·기술 정보 |
| Google | Google 로그인, Google Mobile Ads, UMP | 계정 인증 정보, 기기·광고 ID, 대략적 위치, 이용·진단 정보 |
| Apple | Apple 로그인, App Store 배포 | 계정 인증 정보, 스토어·기기 기술 정보 |
| 비바리퍼블리카 | Apps in Toss 제공 시 플랫폼 기능 | 토스 플랫폼 식별자와 게임·광고 이용 정보 |

각 업체의 보관과 국외 이전은 해당 업체의 개인정보 정책 및 서비스 약관에 따릅니다.

## 4. 보관 및 삭제

- 뒤끝 계정과 게임 데이터: 사용자가 탈퇴할 때까지. 앱에서 즉시 탈퇴를 요청하면 로그인은
  곧바로 차단되고 서버의 최종 삭제 처리에는 최대 1시간이 걸릴 수 있습니다.
- 기기 게임 데이터: 앱을 삭제하거나 앱 안에서 계정 삭제가 성공할 때까지
- 고객지원 기록: 문의 완료 후 법적·분쟁 대응에 필요한 기간
- 광고·진단 데이터: 각 처리 업체가 공개한 정책과 법적 의무에 따른 기간

## 5. 이용자의 선택과 권리

- 소셜 로그인 없이 게스트로 플레이할 수 있습니다.
- `메인 화면 → 설정 → 계정 → 계정 삭제`에서 두 번 확인한 뒤 계정 삭제를 요청할 수
  있습니다. 서버 데이터, 리더보드, 인증 연결과 계정에 연결된 기기 게임 데이터가
  삭제됩니다.
- Apple 로그인 계정은 삭제 전 Apple 재인증을 거쳐 토큰 승인 철회를 먼저 요청합니다.
- 삭제에 문제가 있거나 앱을 사용할 수 없는 경우 `cysbandcs@gmail.com`으로 요청할 수
  있습니다.
- `메인 화면 → 설정 → 플레이·광고 → 광고 개인정보`에서 광고 동의 선택을 다시 확인할 수
  있습니다.

## 6. 아동과 광고

먹점프는 폭력적·선정적 콘텐츠가 없는 캐주얼 게임이며 광고 콘텐츠 등급은 `G`로
제한합니다. 다만 아동만을 대상으로 설계한 서비스는 아닙니다. 법정대리인 동의가 필요한
연령의 사용자는 보호자와 함께 이용해야 합니다.

## 7. 안전조치와 변경

통신 구간은 각 SDK가 제공하는 암호화 연결을 사용합니다. 인증 토큰은 게임의
`PlayerPrefs`나 일반 로그에 기록하지 않으며, API 비밀키를 앱 코드에 넣지 않습니다.
방침이 바뀌면 시행일과 변경 내용을 앱 또는 공식 지원 페이지에 알립니다.
