# 독립 외형 꾸미기

2026-09-26 사용자 실행 승인에 따른 차기 업데이트 범위다. iOS 1.0.3(43)과 토스 20260926-12의 기존 심사·테스트 산출물에는 섞지 않는다. 공통 기능은 양 플랫폼에 적용하며 공개 출시는 별도 상태로 확인한다.

## 외형과 해금

| 갈래 | 외형 | 조건 | 기본 선택 |
|---|---|---|---|
| 스킨 | 까치 둥지 | 누적 아이템 1,000개 | 기존 스킨 선택 유지 |
| 착지 효과 | 댓잎 | 그린 발판에 누적 200회 착지 | 기존 먹 번짐 |
| 분신 외형 | 먹 올챙이 | 원먹을 포함해 12마리 동시 생존 | 본체 따르기 |

세 외형은 능력·점수·성장·충돌 크기를 바꾸지 않는다. 기존 정산 이력의 누적 착지·아이템·최대 생존 수를 소급 인정하고 자동 장착하지 않는다. 착지 누적에는 기존 집계와 동일하게 분신의 착지도 포함한다. 새 조건은 공개 조건이며 숨은 힌트를 요구하지 않는다. 붓 갈래의 저장 공간은 마련하되, 기본 붓 이외의 콘텐츠가 정해지기 전에는 빈 갈래를 표시하지 않는다.

까치 둥지는 원먹 위의 둥지 장식이다. 올챙이는 기존 먹 몸체·표정·애니메이션을 유지하고 작은 꼬리를 붙인다. 선택하면 분신만 해당 외형을 쓰며 본체 사망 후에도 분신 구분을 유지한다. 분신의 분신에도 같은 규칙을 적용한다. 본체 따르기를 선택하면 현재 스킨의 장식과 금색 외형을 따른다. 별도 분신 외형은 능력을 바꾸지 않는다.

## 선택과 미리보기

가운데 먹에 현재 조합을 함께 보여 준다. 스킨·착지·분신 갈래를 골라 외형을 미리 보고, 하단 착용 버튼으로 해당 갈래만 저장한다. 미리보기·갈래 전환·닫기는 저장하지 않으며 다른 갈래는 유지한다. 다시 열면 실제 장착 조합을 보여 준다. 스킨의 일반/특수/히든 목록과 전체 보기를 유지한다.

금색 먹의 구매 권한은 iOS의 검증된 StoreKit 권한만 사용한다. 새 업적 목록에 금색 소유권을 넣지 않는다. 금색과 댓잎을 함께 장착하면 기존 금색 입자와 댓잎이 함께 표시되며 추가 능력은 없다.

## 저장 호환

- 기존 의상 ID 0~62와 63비트 보유 마스크는 확장·재배열하지 않는다. 새 외형은 `skin.magpie_nest.v1`, `landing.bamboo_leaf.v1`, `clone.tadpole.v1` 식별자를 사용한다.
- 계정 성장 저장 버전 14의 `cosmetics` 목록에 새 소유권을 둔다. 버전 13 이력은 기록·재화·기존 소유권을 유지하며 이관한다. 새 버전을 모르는 구 앱이 저장을 덮어쓰지 않도록 상위 버전 거부 경계를 유지한다.
- 같은 계정의 갱신은 새 소유권을 합치고, 다른 계정으로 교체할 때는 합치지 않는다. 알 수 없는 외형 ID는 보존하지만 현재 앱에서 장착 가능한 것으로 해석하지 않는다.
- 장착은 기존처럼 기기 설정이다. `MukJump.Settings.Cosmetics.v1`과 구 스킨·금색 필드를 같은 저장소에서 한 번에 저장하고 실패 시 모두 이전 값으로 되돌린다. 계정에 권한이 없으면 기본 외형을 표시하되 사용자의 원래 선택은 지우지 않는다.
- 판 시작에 스킨·착지·분신 선택을 고정하고 광고 부활·분신 생성에서는 다시 읽지 않는다. 구매 권한의 회수는 기존 금색 권한 검사로 반영한다.
- 기존 리더보드의 스킨 ID 형식은 유지한다. 새 둥지는 기본 먹 ID로 전송하며, 새 서버 필드나 사용자 정보 저장을 추가하지 않는다.

## 효과와 확인 범위

댓잎은 기존 착지 호출의 묶음 제한을 공유한다. 고정 방출기 하나를 재사용하며 품질별 동시 잎 한도는 6/9/12개다. 일시정지에는 수명이 멈추고 움직임 줄이기에는 장식 입자를 내보내지 않는다. 실제 모바일 성능은 편집기 테스트로 확정하지 않는다.

성장 수치는 유지한다. 먹 용량·소모 성장 선택 상세에서 현재 대비 다음 구매의 최대 그리기 길이 증가율과 기존 비용을 함께 확인한다.

실제 iPhone 검증에서는 상품 조회·구매·복원·재실행뿐 아니라 App Store 계정 전환 뒤 앱 복귀 시 광고 제거·금색 권한이 올바른지도 확인한다. 토스는 광고 후 소리, 재실행 저장·착용 확인이 남아 있다. 이 목록은 실제 성공 증거가 아니다. 기존 Firebase/GA4 자료는 접근 권한을 확보한 뒤 읽으며, 새 계측·유료 서버를 만들지 않는다.

## 원화 출처

내장 이미지 생성 도구로 만든 투명 PNG 세 장을 `Assets/Resources/MukJump/Cosmetics/`에 보관한다. 가져오기 설정은 씬 빌더의 `ConfigureCosmeticSprites`가 관리한다. 외부 에셋을 다운로드하지 않았다.

- 댓잎: 한 장의 가늘고 뾰족한 먹색 대나무 잎, 배경·다른 물체 없이 투명 배경.
- 까치 둥지: 검정·한지색의 작은 까치 새끼와 낮고 둥근 나뭇가지 둥지, 거친 수묵 선, 투명 배경.
- 먹 올챙이: 몸체 없이 짧게 굽은 먹색 꼬리만, 기존 먹의 실루엣·표정에 겹쳐 쓰는 투명 장식.
