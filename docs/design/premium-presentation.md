# 광고 제거 구매 안내와 금색 먹

2026-09-26 사용자 요청에 따른 로컬 구현이다. 기존 iOS 1.0.3(43) 심사 바이너리와 토스 20260926-12 테스트 패키지는 변경하지 않는다.

- 구매창은 모든 광고 제거 → 반짝이는 금색 먹 포함 → 실제 스토어 가격과 구매 버튼 순서로 표시한다. 한 번 구매로 계속 이용하며 배너·전면·보상형 부활 광고를 모두 제거한다. 부활은 기존 조건과 한 판 1회 한도를 유지한다.
- 구입 복원 실행 버튼은 설정에만 둔다. 구매창에는 설정 위치를 알려 주는 보조 문구만 둔다. 구매·복원·취소·실패·권한 회수는 기존 StoreKit 공급자의 검증을 사용하며 화면에서 권한을 부여하지 않는다. 처리 중 중복 요청을 차단하고 설정에서 복원 결과를 갱신한다.
- 금색 먹은 몸체 명암 안에서 약 3.8초 주기로 금빛 결이 흐른다. 원본 알파·흰 눈·어두운 동공·애니메이션·충돌·능력은 유지한다. 기존 월드/UI 공용 재질 두 개와 텍스처 읽기 1회만 사용하며 반복 입자 생성이나 새 패키지·후처리는 추가하지 않는다. 움직임 줄이기 설정에서는 정적인 금색을 유지한다.
- iOS의 검증된 구매 권한만 금색과 광고 제거를 제공한다. 토스에는 구매·복원 버튼이나 해당 혜택을 노출하지 않는다.
- 사용자가 언급한 ‘용사님 돌았어요?’의 정확한 광고 제거/2배속 구매창은 확보하지 못했다. 요청한 정보 우선순위를 적용했으며 화면을 그대로 복제하거나 2배속 혜택을 추가한 것은 아니다.
