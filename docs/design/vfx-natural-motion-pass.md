# 수묵 이펙트 자연스러움 개선 — 2026-09-05

목표: 캐릭터의 힘이 먹 튐으로 이어지고, 충격 뒤 입자가 감속하며 종이에 스며들도록 한다.
레이아웃·밸런스·판정·광고·원본 아트는 변경하지 않는다. 기존 작성자의 변경을 보존한다.

## 적용 순서

1. 공통 동작: 순간 충격 → 감속 → 잔향. 고리의 시간에 따른 과한 출렁임을 없애고 두께를 가늘게 마무리한다.
2. 점프·착지·먹선: 탄도 먹 튐과 늦게 드러나는 갈필 가루를 구분한다. 화면 선두 한 명의 빠른 공중 이동에만 짧은 먹 잔향을 남긴다.
3. 벽·피격·위험: 튀는 방향을 사건에 맞춘다. 방사형 장식을 반복하지 않는다.
4. 방어막·50m 상승·분신: 기존 고유 실루엣을 유지하고 파편 감속, 크기·투명도 마무리를 통일한다.
5. 실제 Game View 촬영, 자동 회귀, Low/Medium/High/Reduced 검증. 실기 발열·GPU 승인은 별도다.

## 제약과 타임라인

- 접촉: 0ms 핵심 먹방울, 약 40–100ms 갈필이 드러남, 300–850ms 감속·소멸.
- 공중 잔향: 최소 100ms 간격, 실제 이동량 필요, 프레임당 최대 한 번. 정지·선두 교체·순간이동·복귀 시 catch-up 없음.
- 벽 충돌: 벽에서 안쪽 방향으로만 먹 튐. 실제 반사 속도는 그대로.
- 공통 방울: 450ms 이내, 충격 후 잠깐 형태 유지 → 얇아지며 소멸. Reduced는 이동·회전 없이 표시.
- 파티클 3개 / 공유 Material 2개 / Low 37·Medium 62·High 90 상한 그대로. 공중 잔향은 접촉 슬롯을 남긴다.
- 촬영 피드백 반영: 상승 붓 꼬리는 몸높이 7배 → 3.8배로 줄이고 폭은 0.64배 → 0.22배로 가늘어진다.
  긴 세로 막대 인상을 줄이고 1.5초에 투명해진다. 상승 거리·속도·풀 반납 시간은 유지한다.
- 기존 8선·16방울·합성 3묶음 상한 그대로. 패키지·Renderer Feature·HDR 추가 없음.
