# 개발용 연출 시나리오

옵션의 `DEBUG · 연출 시나리오`는 짧은 영상 촬영과 기능 확인을 위해 서로 다른
게임 중반 상황을 다음 시작부터 바로 구성한다. Unity Editor와 Development Build에서만
보이며 일반 출시 빌드에는 생성되지 않는다.

## 사용 순서

1. 로비에서 `옵션`을 연다.
2. `DEBUG · 연출 시나리오`에서 상황 1~5 중 하나를 고른다.
3. `선택 완료`로 옵션에 돌아온 뒤 옵션을 닫고 `시작`을 누른다.
4. 정상 시작 흐름 뒤 선택한 맵·먹떼·성장 빌드·연출이 즉시 적용된다.
5. 원래 진행도로 확인하려면 `일반 플레이로 초기화`를 고른다.

## 상황 구성

| 상황 | 시작 구성 | 성장 빌드 | 시작 연출 |
|---|---|---|---|
| 1 · 먹떼 행진 | 260m 바람 능선, 총 10마리 | 먹떼 / 벽 자동점프 / 넓은 벼루 | 풍향 전환, 풍맥 발판 |
| 2 · 황금 먹비 | 510m 먹비 계곡, 총 3마리 | 먹피 / 고른 박자 / 가는 붓끝 | 황금 붓, 먹물방울 50m 상승 |
| 3 · 해태 급습 | 760m 검은 절벽, 총 2마리 | 숨 고르기 / 벽 자동점프 / 마르는 먹 | 전원 방어막, 해태 경고와 하강 |
| 4 · 천상 도약 | 1260m 월련 성해, 총 5마리 | 먹피 / 2단점프 / 넓은 벼루 | 상승기류, 먹물방울 50m 상승 |
| 5 · 천하수 먹떼 | 1510m 천하수, 2→12마리 | 먹떼 / 2단점프 / 마르는 먹 | 먹물방울 50m 상승 3회, 사이사이 먹분신 5회 |

## 데이터 보호 규칙

- 시나리오 성장은 해당 판의 `PermanentGrowthRunSnapshot`에만 적용한다.
- 영구 성장 구매·장착, 먹빛, 최고 기록과 튜토리얼 저장은 수정하지 않는다.
- 시나리오 판은 고도 순간이동과 함께 기록·영구 성장 보상 대상에서 제외한다.
- 실제 로비의 `StartGameFromMenu`와 Playing 상태 전환을 우회하지 않는다.
- 선택값은 현재 Play 세션의 메모리에만 남고 앱 저장에는 기록하지 않는다.
