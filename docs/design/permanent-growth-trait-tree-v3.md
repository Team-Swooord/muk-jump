# 영구 성장 먹나무 확정안

> 기준일: 2026-08-04
> 상태: 런타임 반영 중 · 최종 플레이 검증은 사용자 요청 시 진행
> 범위: 로비의 영구 성장만 다룬다.

## 1. 최종 원칙

- 플레이 중 무작위 증강·성장 두루마리·증강 카드·도감은 사용하지 않는다.
- 성장 재화는 정상 도전 결과에서 얻는 `먹빛` 하나다. UI에서는 먹방울 아이콘과
  숫자만 표시해 월드 아이템 설명과 혼동하지 않게 한다.
- 모든 노드는 먹빛 1개로 한 번만 해금한다.
- 큰 분류는 `생존 / 도약 / 먹 운용` 세 가지다.
- 각 분류는 공통 뿌리 1개 뒤 세 갈래로 나뉜다. 각 갈래는 일반 노드 3개와
  마지막 비기 1개로 끝난다.
- 총 노드 수는 `3 × (뿌리 1 + 3갈래 × 4노드) = 39개`다.
- 일반 노드는 해금 즉시 항상 적용된다. 비기는 같은 분류에서 하나만 장착한다.
- 프리셋은 두지 않는다. 현재 장착 비기 세 개만 저장한다.
- 점수 배율, 아이템 출현 확률, 시작 분신 수는 성장 효과에 넣지 않는다.

```text
                     A1 ─ A2 ─ A3 ─ KA
                    /
분류 뿌리 R ──────── B1 ─ B2 ─ B3 ─ KB
                    \
                     C1 ─ C2 ─ C3 ─ KC
```

비기는 자기 갈래의 세 일반 노드와 분류 뿌리를 모두 해금한 뒤 열 수 있다.
첫 비기까지 필요한 먹빛은 뿌리 1 + 일반 3 + 비기 1, 총 5개다.

## 2. 생존 — 13개

| 경로 | 일반 노드 3개 | 마지막 비기 |
|---|---|---|
| 내구 | 피격 후 무적 +0.05초 → +0.05초 → 최대 체력 +1 | `마지막 먹숨`: 마지막 생존자가 장애물로 죽을 때 판당 1회 체력 1로 생존. 추락 제외 |
| 피격 안정 | 수평 속도 보존 → 상승 반동 완화 → 피격 뒤 무적 +0.08초 | `흐트러지지 않음`: 12초마다 첫 비치명 피해는 체력만 잃고 속도·접착 유지 |
| 먹떼 보호 | 새 분신 보호 +0.15초 → 분신 생성 시 원본 보호 0.25초 → 분신 사망 시 최저 체력 생존자 +1(공용 30초) | `함께 맺힘`: 먹분신 획득 시 최저 체력 +1, 전체 보호 0.35초 |

공통 뿌리는 피격 후 무적 +0.05초다. 일반 노드를 모두 해금하면 기본 체력은
3→4, 피격 후 무적은 총 +0.15초가 된다. 추락을 상시 무효화하는 효과는 두지 않는다.

## 3. 도약 — 13개

| 경로 | 일반 노드 3개 | 마지막 비기 |
|---|---|---|
| 준비시간 | 단계마다 자동 점프 준비시간 -1.5% | `벽의 먹발`: 하강 중 측면 벽에 잠시 붙어 충전 뒤 안쪽으로 자동점프 |
| 점프 힘 | 단계마다 기본 자동 점프 힘 약 +1.67% | `다섯 번째 먹자리`: 일반 1차 자동점프 5회마다 폭 3.4m·수명 6초의 단방향 발판 생성 |
| 점프 높이 | 단계마다 정점 높이 약 +2.08% | `겹친 먹발`: 첫 정점에서 이륙 수직속도 40%의 자동 2단점프, 공용 12초 |

공통 뿌리는 자동 점프 준비시간 -1.5%다. 완성 상시값은 준비시간 -6%, 기본 점프
힘 +5%, 정점 높이 +6.25%다. 세 비기는 모두 구매할 수 있지만 하나만 장착해
안전 발판·벽 점프·2단점프가 동시에 연쇄 발동하지 않게 한다.

## 4. 먹 운용 — 13개

| 경로 | 일반 노드 3개 | 마지막 비기 |
|---|---|---|
| 총량 | 총 먹자리 +2% → +2% → +2% | `넓어진 화폭`: 총 먹자리 +6% |
| 절약 | 먹자리 점유 -1.5% → -1.5% → 1.5m 이하 획 점유 -6% | `한 붓의 길`: 모든 획 점유 -5% |
| 여운 | 오래된 획 소멸 +0.10초 → +0.10초 → 소멸 시작 +0.10초 지연 | `붙잡은 먹길`: 소멸 시간 +0.45초 |

공통 뿌리는 총 먹자리 +2%다. 기본 먹자리는 18m이며 회복과 시간제 자연 소멸은 없다.
완성 상시값은 총 먹자리 +8%, 모든 획 점유 -3%, 짧은 획 점유 추가 -6%,
소멸 +0.20초와 시작 지연 +0.10초다. 비기는 세 효과 중 하나만 장착한다.

### 먹자리 기준 밸런스

- 기본 18m는 2.5~3m짜리 실전 획 약 6~7개를 남기는 기준이다. 예전 4개 슬롯보다
  짧은 보정 획은 더 허용하지만, 긴 획을 남발하면 오래된 길이 빠르게 교체된다.
- 모든 일반 노드 해금 후 `넓어진 화폭`은 총 20.52m, `한 붓의 길`은 긴 획 기준
  약 21.13m의 실효 먹자리를 제공한다. 두 선택의 순수 유지량 차이는 약 3%라 한쪽이
  정답이 되지 않고, 짧은 획을 주로 쓰는 플레이만 절약 갈래에서 추가 이득을 얻는다.
- `붙잡은 먹길`은 총량을 늘리지 않고 기본 1.1초 소멸을 최대 1.75초로 완화한다.
  충돌체도 같은 진행도로 줄어들어 이미 사라진 부분을 밟는 숨은 판정은 만들지 않는다.

## 5. 재화와 저장

- 첫 정상 게임오버: 고도와 무관하게 먹빛 1개 보장
- 이후 정상 도전: 진행 고도 12m 이상이고 실제 플레이 20초 이상이면 1개
- 최초 최고 기록 100 / 250 / 500 / 750 / 1000m: 이정표마다 보너스 1개
- 디버그 사용, 중도 로비 복귀, 이미 정산한 run ID: 0개
- 이정표를 모두 받으면 34번, 받지 못하면 39번의 유효 보상 판으로 전체 완성

`PermanentGrowthProfile`은 먹빛, 소유 node ID, 분류별 장착 비기 ID와 정산 run ID를
저장한다. 플레이 시작 시 `PermanentGrowthRunSnapshot`을 만들고 해당 판이 끝날
때까지 고정한다. 로비에서 노드를 바꿔도 진행 중인 판에는 소급하지 않는다.

정상 저장은 최신 검증본을 backup에도 남긴다. 손상 저장과 현재 코드보다 미래의
schema/balance 저장은 자동 초기화하거나 다운그레이드하지 않고 원문 그대로 잠근다.
로비 시작은 복구 전 차단하며 성장 화면에서 `백업 복원` 또는 2회 확인 `새로 시작`을
고른다. 교체 전 원본은 quarantine에 남긴다.

45노드 저장을 39노드로 읽을 때 제거된 도약 4·5단계 ID는 지우고 각 고유 ID당
먹빛 1개를 환급한다. 기존 비기 ID는 유지해 저장 호환을 보존한다.

## 6. UI 규칙

- 한지 전체 화면 위에 큰 먹나무를 배치하고, 뿌리에서 공동 노드를 지난 뒤
  생존·도약·먹 운용 세 큰 가지가 나뉘는 흐름을 한눈에 읽게 한다.
- 각 큰 가지 안에서는 세 경로를 규칙적인 직선이 아니라 자연스러운 잔가지로
  분리하되, 부모–자식 먹선은 끊기지 않게 연결한다.
- 노드 뒤에는 진한 먹 받침을 두고 잠금 봉오리, 해금 빨간 열매, 선택 먹고리,
  장착 금빛 고리를 별도 레이어로 합성한다.
- 지도에는 긴 설명을 넣지 않는다. 노드를 탭하면 고정 팝업에서 아이콘과 이름,
  `점프 높이 +2.08%` 같은 효과 수치 한 줄, 짧은 설명과 비용만 보여 주고
  `강화하기` 또는 `장착`을 누른다. 상태·적용 방식·효과 접두어를 반복하지 않는다.
- 먹 운용 오른쪽 갈래와 도약 왼쪽 갈래의 열매·터치 영역은 겹치지 않아야 하며,
  도약 표찰과 전체 계보를 함께 오른쪽으로 이동해 가지 연결을 유지한다.
- 구매 성공 시에만 짧은 먹 번짐과 금빛 고리를 표시한다. 장식용 빨간 점은 쓰지 않는다.

## 7. 검증 기준

- 카탈로그가 정확히 39개이며 분류별 13개인지 확인한다.
- 각 분류가 뿌리 1개, 일반 노드 9개, 비기 3개인지 확인한다.
- 모든 비기의 부모가 같은 경로의 세 번째 일반 노드인지 확인한다.
- 노드 비용이 모두 1이고, 분류마다 장착 비기가 최대 하나인지 확인한다.
- 제거된 도약 노드를 가진 구 저장의 환급·비기 보존을 확인한다.
- 실제 난도와 체감은 정적 테스트로 단정하지 않는다. 최종 플레이 테스트는 사용자가
  요청할 때 별도로 수행한다.
