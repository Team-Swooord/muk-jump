# 영구 성장 먹나무 확정안

> 기준일: 2026-08-06
> 상태: 런타임 반영 · 최종 플레이 검증은 사용자 요청 시 진행
> 범위: 로비의 영구 성장만 다룬다.

## 1. 최종 원칙

- 플레이 중 무작위 증강·성장 두루마리·증강 카드·도감은 사용하지 않는다.
- 성장 재화는 정상 도전 결과에서 얻는 `먹빛` 하나다.
- 모든 열매는 먹빛 1개로 한 번만 해금하며 해금 기록은 영구 보존한다.
- 실제 도전에는 각 분류에서 선택한 A/B/C 한 갈래와 공용 뿌리만 적용한다.
  이미 소유한 갈래는 무료로 교체할 수 있고 새 갈래 구매 시 그 갈래가 바로 선택된다.
- 큰 분류는 `생존 / 도약 / 먹 운용` 세 가지, 각 분류는 13개 stable ID를 쓴다.
- 일반 열매는 한 가지 수치만 반복 강화하고, 각 잔가지 마지막 K 열매는 수치와
  계보 규칙을 함께 완성하는 **결실 패시브**다.
- 생존 피격 여유 갈래는 `S00 / S-B1~B3` 뒤 `S-KB` 장애물 피격 생존 방어막,
  피격 안정 갈래는 `S-C1~C3` 뒤 `S-KC` 먹분신 아이템 추가 생성 +1 패시브로
  끝난다. 내부 Kind와 구 장착 필드는 기존
  저장·레이아웃 호환용으로만 남긴다.
- 총 노드 수는 `3 × 13 = 39개`, 전체 필요 먹빛도 39개다. 한 판에 적용되는
  최대 노드는 공용 뿌리를 포함해 분류별 5개, 총 15개다.
- 점수 배율, 아이템 출현 확률, 시작 분신 수는 성장 효과에 넣지 않는다.

```text
                     A1 ─ A2 ─ A3 ─ 결실
                    /
분류 뿌리 R ──────── B1 ─ B2 ─ B3 ─ 결실
                    \
                     C1 ─ C2 ─ C3 ─ 결실
```

공용 뿌리는 가운데 B 경로의 1단계다. A/C 경로는 뿌리를 선행 조건으로만 공유하고,
실제 A/C 수치는 각 경로에서 단계적으로 증가한다. 단, 생존 B 경로는 앞 네 열매만
피격 무적 시간을 올리고 마지막 열매는 숨 고르기 결실, C 경로는 앞 세 열매만
피격 안정 수치를 올리고 마지막 열매는 먹떼 결실 패시브로 전환한다.
생존의 먹발 버팀·먹떼 결실 줄과 먹 운용의 넓은 벼루 줄은 서로 부모 관계가 없으며,
지도에서도 열매 중심 사이를 최소 280px 띄워 두 계보의 가지가 붙어 보이지 않게 한다.

## 2. 생존 — 13개

| 경로 | 단계별 효과 | 완성값 |
|---|---|---|
| 먹피 결실 | `S-A1 / A2 / A3`은 본체 최대 체력 +1, 최종 `S-KA`는 본체와 분신 최대 체력 +1 | 본체 1 → 5칸, 분신 1 → 2칸 |
| 숨 고르기 | `S00 / S-B1 / B2 / B3` 각각 피격 뒤 무적 +0.04초 | 총 +0.16초 |
| 숨 고르기 결실 | 최종 `S-KB`에서 본체 체력 +1, 장애물 피해 뒤 살아남으면 방어막 생성 | 본체 2칸, 다음 피격 1회 방어 |
| 먹발 버팀 | `S-C1 / C2 / C3` 각각 피격 수평 밀림 -6% | 수평 속도 보존율 82% → 64% |
| 먹떼 결실 | 최종 `S-KC`에서 먹분신 아이템 생성 최대 +1 | 아이템 1회 기본 1 → 최대 2마리 |

먹떼 결실은 게임 시작 분신 수를 바꾸지 않는다. 실제 `먹분신` 아이템을 획득한 순간에만
기본 1마리에 추가 1마리를 더하며, 현재 먹떼가 24마리 상한에 가까우면 남은 자리만 채운다.
숨 고르기 결실의 방어막은 실제 피해 뒤 살아남은 본체에만 생성된다. 분신은 기본 1체력이며
먹피 결실 선택 적용 중에는 2체력이 된다. 기존 아이템 방어막은 본체와 분신이 각자 소유하며,
방어막으로 막은 피격과 체력이 0이 되는 치명 피해에는 방어막을 사후 생성하지 않는다.
화면 하단 추락은 장애물 피격이 아니므로 새 방어막을 만들지 않는다.
분신 보호 시간·원본 보호·분신 사망 회복·분신 유대 패시브는 영구 성장에서 제거한다.
새 분신의 기본 1초 충돌 안전시간은 겹침 사망을 막는 물리 안전장치로만 유지한다.

## 3. 도약 — 13개

| 경로 | 단계별 효과 | 완성값 |
|---|---|---|
| 고른 박자 결실 | `J-A1 / A2 / A3 / KA` 각각 준비시간 -1.5%, `J-KA`는 직접 그린 먹선의 다음 준비 추가 -25% | 일반 -6%, 그린 먹선에서 추가 -25% |
| 돋는 먹발 결실 | `J00 / J-B1 / B2 / B3 / KB` 각각 점프 힘 +1%, `J-KB`는 직접 그린 먹선 도약 힘 추가 +10% | 기본 +5%, 그린 먹선에서 추가 +10% |
| 높은 먹발 결실 | `J-C1 / C2 / C3 / KC` 각각 점프 정점 높이 +1.5625%, `J-KC`는 마지막 생존자가 화면 하단에 있을 때 낙하 완화 | 높이 +6.25%, 낙하 속도 50% 완화·공용 14초 |

낙하 완화는 위로 튀기거나 체력을 회복하지 않고 현재 하강 속도만 절반으로 줄인다.
벽 매달림, 5회 안전 발판, 자동 2단점프 같은 특수 비기는 사용하지 않는다. 측면 벽은
기본 물리 규칙으로 상승분을 끊고 화면 안쪽으로 반사해 무한 벽타기만 막는다.

## 4. 먹 운용 — 13개

| 경로 | 단계별 효과 | 완성값 |
|---|---|---|
| 넓은 벼루 결실 | `I-A1 / A2 / A3 / KA` 각각 최대 먹 용량 +37.5%, `I-KA`는 용량 안의 먹선 선명 유지 +1초 | 3.2m → 8.0m(+150%), 선명 유지 4.4초 |
| 가는 붓끝 결실 | `I00 / I-B1 / B2 / B3 / KB` 각각 획당 먹 소모 -2%, `I-KB`는 1.5m 이하 짧은 획 추가 -15% | 일반 획 -10%, 짧은 획은 추가 -15% |
| 마르는 먹 결실 | `I-C1 / C2 / C3 / KC` 각각 먹 게이지 회복 속도 +10%, `I-KC`는 마름 시작 -0.8초 | +40%, 먹 반환 조기 시작 |

기본 최대 먹 용량 3.2m는 실전 발판 약 한 획, 완성 8.0m는 약 2.5획 기준이다. 그린 획은
기본 3.4초 동안 선명하게 남은 뒤 1.1초 동안 가장 오래된 시작점부터 마른다. 넓은 벼루
결실을 열면 총량을 넘기지 않은 먹선의 선명 시간이 4.4초가 된다. 회복 성장은
페이드 구간을 `1.1 / 회복 배율`로 줄이고, 마르는 먹 결실은 마름 시작을 0.8초
앞당겨 게이지 반환을 빠르게 한다. 네 단계를 모두 열면 페이드는 약 0.79초다.

총량을 넘기면 가장 오래된 획부터 같은 페이드 규칙으로 밀려난다. 황금 붓은 8초 동안
총량 초과 정산만 보류한다. 판 한정 최대 먹 용량 확장 아이템은 폐기했으며, 총량 증가는
이 영구 성장 경로에서만 제공한다.

## 5. 재화와 저장

- 정상 게임오버 결과 고도를 계정 `누적 거리`에 한 번 더한다.
- 누적 거리 문턱을 통과할 때마다 먹빛 1개를 지급한다. 한 판에 여러 문턱을 넘으면
  그 수만큼 한 번에 지급한다.
- 디버그 판, 중도 로비 복귀, 이미 정산한 run ID는 누적 거리와 먹빛을 바꾸지 않는다.
- 39번째 먹빛 이후에도 누적 거리는 통계로 기록하되 추가 먹빛은 지급하지 않는다.

| 단계 | 간격 | 구간 지급 | 구간 종료 누적 거리 |
|---|---:|---:|---:|
| 1~5 | 20m | 5개 | 100m |
| 6~13 | 50m | 8개 | 500m |
| 14~26 | 100m | 13개 | 1800m |
| 27~39 | 150m | 13개 | 3750m |

`PermanentGrowthProfile`은 먹빛, 소유 node ID, 구버전 호환 장착 ID와 정산 run ID를
저장한다. 기존 39개 stable ID는 삭제하지 않고 새 단일 수치 의미로 승계한다. 따라서
예전 `낮은 흔들림`, 분신 보호, 특수 비기 열매를 이미 산 저장도 같은 위치의 새 수치
열매를 소유한다. 기존 장착 ID는 이제 해당 계보의 선택 A/B/C를 가리킨다. 비어 있으면
소유 노드가 가장 많은 갈래를 결정적으로 선택한다. 플레이 시작 시 만든
`PermanentGrowthRunSnapshot`은 판 종료까지 고정한다.

상단 `노드 초기화`를 두 번 누르면 소유 노드 수만큼 먹빛을 전액 환급하고 노드·선택만
비운다. 누적 거리, 받은 보상 단계, 정산 run ID는 지우지 않는다.

정상 저장은 검증본을 backup에도 남긴다. 손상 저장과 미래 schema/balance 저장은 자동
초기화하지 않고 읽기 전용으로 잠근다. 성장 화면에서 `백업 복원` 또는 2회 확인
`새로 시작`을 고르며, 교체 전 원본은 quarantine에 남긴다.

## 6. UI 규칙

- 한지 전체 화면의 큰 먹나무 위에 생존·도약·먹 운용 세 가지와 잔가지를 배치한다.
- 지도에는 긴 설명을 넣지 않는다. 노드를 탭하면 DIM 위 고정 팝업에서 아이콘, 이름,
  효과 한 줄, 짧은 설명, 비용과 `강화하기`만 보여 준다.
- 내부적으로 Keystone Kind인 마지막 열매는 화면에 `결실`로 표시한다. 소유한 비활성
  갈래 상세에는 `이 줄기 적용`, 현재 갈래에는 `적용 중`을 표시하며, 상세에는 마지막
  수치와 전용 패시브를 함께 적는다.
- 한 갈래를 선택하면 그 줄기는 선명하게 유지하고 나머지 두 갈래의 가지·열매 농도를
  낮춘다. 비선택 가지에는 기존 먹붓 질감의 가시덩굴을 감아 잠금이 아닌 `현재 미적용`
  상태를 보여 준다. 가시 이미지는 레이캐스트를 받지 않으며 노드 상세 확인과 무료
  갈래 교체는 계속 가능하다. 계보에 선택이 없으면 세 갈래 모두 가시 없이 표시한다.
- 잠금은 먹 봉오리, 해금은 빨간 열매, 현재 선택은 먹고리로 구분한다. 결실은 마지막
  일반 열매보다 310px 위에 배치하고 표면만 조금 크게 만든다. 잠긴
  결실도 얇은 금빛 후광으로 목적지를 보여 주고, 해금하면 큰 붉은 열매와 진한 금빛
  후광으로 완성 상태를 나타낸다.
- 상단의 먹빛·누적 거리·세 계보 요약은 상세창과 같은 진회색 먹 패널 한 장 위에
  밝은 글자로 표시한다. 누적 거리 막대는 520×32px이며 현재 구간 진행률을
  `0 / 100%` 형식으로 막대 안에 표시한다. 같은 패널에 2회 확인 `노드 초기화`를 두고,
  로비 버튼은 나무와 겹치지 않는 Safe Area 왼쪽 아래에 둔다.
- 성장 화면 상단 요약은 `본체 체력 1→N / 무적·방어막 / 밀림 82→N%·분신 체력 1→N·생성 1→N`, `준비 / 점프력 / 높이`,
  `최대 먹 용량 / 획 소모 / 회복`의 실제 누적값만 보여 준다.

## 7. 검증 기준

- 카탈로그가 정확히 39개이며 분류별 13개인지 확인한다.
- 일반 수치와 기존 39개 stable ID·먹빛 총비용이 유지되는지 확인한다.
- 생존 `S00 / S-B1~B3`가 피격 무적 +0.04초씩, `S-KB`만 장애물 피격 생존 뒤
  1회 방어막인지 확인한다.
- 생존 `S-C1~C3`가 피격 수평 밀림 -6%씩, `S-KC`만 먹분신 추가 생성 +1인지 확인한다.
- 선택한 갈래만 적용되어 생존·도약·먹 운용 안의 다른 두 갈래 수치가 섞이지 않는지
  확인한다. 공용 뿌리는 선택과 무관하게 적용되어야 한다.
- 각 완성값이 본체 체력 5·분신 체력 2, 피격 무적 +0.16초와 본체 체력 2·방어막,
  수평 속도 보존율 64%·먹분신 아이템 1회 2마리, 준비 -6%, 점프 힘 +5%, 높이
  +6.25%, 최대 먹 용량 8.0m, 획 소모 -10%, 회복 +40% 중 해당 선택과 일치하는지 확인한다.
- 도약 결실의 그린 먹선 준비 -25%·도약 힘 +10%·하단 낙하 완화 50%/14초,
  먹 운용 결실의 선명 유지 +1초·짧은 획 추가 -15%·마름 시작 -0.8초를 확인한다.
- 노드 초기화 뒤 구매 먹빛만 전액 환급되고 누적 거리와 수령 단계가 유지되는지 확인한다.
- 먹분신 아이템은 남은 먹떼 슬롯 수만 생성하고 24마리일 때 소비되지 않아야 한다.
- 제거한 분신 보호·마지막 숨·피격 보존·벽 매달림·안전 발판·2단점프가 런 스냅샷에서
  발동하지 않는지 확인한다.
- 실제 난도와 체감은 정적 테스트로 단정하지 않는다. 최종 플레이 테스트는 사용자가
  요청할 때 별도로 수행한다.
