# 모바일 효과·피드백 폴리시 — 2026-09-05

## 방향과 참고

수묵 원화를 유지하며 **행동의 위치·방향·강도와 결과가 이어져 보이도록** 정리한다.
반복 점프에는 작은 발밑 먹획, 중요한 아이템에는 고유 핵심 효과를 둔다.

- [Alto’s Odyssey 공식 프레스킷](https://altosodyssey.com/press/): 유동적인 이동,
  지형별 시각 차이, 변화하는 날씨와 수작업 오디오를 참고 대상으로 삼았다.
- [Jetpack Joyride 2 공식 페이지](https://www.halfbrick.com/games/jetpack-joyride-2)와
  [공식 게임플레이 공개 자료](https://www.youtube.com/watch?v=qEz2ZjBmdp4):
  이동과 아이템 효과의 차이를 비교하기 위한 자료다.
- 먹점프의 이번 수치·형태·우선순위는 자체 설계다. 타 게임의 소스·원화·음원·
  효과 타이밍을 복사하지 않았고, 외부 에셋이나 새 패키지도 설치하지 않았다.

### 유지한 계약

- 실제 점프 속도·50m 상승·8초 황금 붓·아이템 적용 시점·방어막 소유권·저장·광고는 그대로다.
- 점프·착지는 같은 프레임에서 병합한다. 100/120ms 후속 중복 억제는 표시 지연이 아니다.
  뒤늦은 강한 충격(정규화 강도 +0.3)과 첫 공중 재도약은 억제를 우회한다.
- 아이템 원화의 흡수는 기존 SpriteRenderer 하나로 처리한다. trigger는 즉시 비활성화하고
  풀 재사용 시 색·크기·대상·반납 상태를 초기화한다. 일시정지에서는 진행하지 않는다.
- 공용 순간 풀 8선/16방울, 합성 풀 3묶음 및 Low/Medium/High 상한은 늘리지 않는다.
- 원본 PNG·씬 YAML·동시 작업자의 광고/출시 변경·`docs/ai-usage-log.md`는 수정하지 않는다.
- iOS 기본 진동은 매 착지에 사용하지 않고 방어막 파괴·사망에만 유지한다.
- `InkGaugeTint`는 HUD당 Material 1개를 소유하고 비활성화 시 해제한다.
  [Unity Graphics.DrawTexture](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Graphics.DrawTexture.html)의
  sourceRect/material 경로를 사용하며 텍스처 복제·CPU readback은 런타임에 없다.

## 검증 상태

- 런타임/에디터 C# 컴파일 통과. 로그: `output/quality-polish/compiler/runtime.log`, `editor.log`.
- `MobileFeedbackPolishTests`에 황금 시작·연장·종료, reduced 색 전환, 픽업 1회 반납·재사용,
  24개체 호출 순서, reduced 합성 재사용, 카메라 선두 일치, GPU 검정 픽셀 금색 치환 검사를 추가했다.
- 기존 `PlayerSafetyTests`는 즉시 방어막 적용·trigger 해제와 흡수 후 반납을 구분하도록 갱신했다.
- 보조 검토자는 읽기 전용으로 두 차례 검토했고, 화면 밖 후보·방어막 중복·카메라 선두·
  검은 원화의 곱셈 tint 문제를 추가 발견해 반영했다.
- 최종 두 검토자의 소스 수준 판정은 승인이다. cooldown 예외·0.65초 반납의 실시간 테스트는
  추가 확인 대상이며 정적 승인을 엔진·실기기 승인으로 간주하지 않는다.
- Unity 6000.5.9f1의 열린 에디터에서 `MobileFeedbackPolishTests` **7/7 통과**.
  GPU 검정 픽셀 금색 치환 검사도 포함한다. 최초 실행의 1건 실패는 EditMode에서
  비활성화 메시지를 자동 호출한다고 가정한 테스트 구성 문제였다. 기존 리소스 테스트와
  동일하게 `OnDisable` 진입점을 명시적으로 호출한 뒤 전체 7개를 재실행했다.
- 실제 Game View 540×960을 20fps 고정 게임 시간으로 캡처해 4개 GIF(총 560프레임)를
  생성했다. `output/quality-polish/captures/20260905-103609/`의 `evidence.txt`,
  `complete.txt`, `mobile-feedback-tests.xml`, `gifs/`가 증거다.
  아이템·획 위치를 제어한 촬영용 세션이며 장애물 스포너를 끄고 메모리 저장소를 사용했다.
  프레임 합성·보간·효과 후처리는 하지 않았고 GIF만 432×768로 축소했다.
- 방어막 획득·피격 소모 후 체력 3 유지, 50m 상승 아이템 발동, 황금 붓 금색 표시 및
