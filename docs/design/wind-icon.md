## 최종 생성 프롬프트

Use case: stylized-concept. Asset type: one production-ready game HUD icon for a Korean ink-wash game, displayed very small at 44 by 44 pixels. Primary request: a single rounded wind symbol with an East Asian sumukhwa/sumi-e brush aesthetic, replacing a red square seal. Subject: three bold flowing curved gust strokes with curled tips, arranged into one balanced approximately circular silhouette. Make it recognizably wind, airy and graceful, not a cyclone funnel, not a yin-yang symbol and not a circular frame around a separate symbol. Hand-painted near-black charcoal ink with subtle dry-brush fibers and soft natural ink bleeding, clear open negative space and sturdy strokes legible at tiny size. Square canvas, centered icon occupying about 88 percent of the canvas, equal narrow padding; the complete icon must be in frame. Genuinely transparent PNG background, including all gaps between strokes. No paper rectangle, no colored disk, no red, no text, no Chinese/Korean characters, no border, no shadow, no glow, no extra symbols, no UI mockup. Create exactly one icon.
