# 먹나무 모듈 가지 스프라이트 생성 프롬프트

## 함께 첨부할 기준 이미지

1. `Assets/Resources/MukJump/UI/PermanentGrowth/pg_tree_trunk.png`
2. `docs/ai-artifacts/ui/permanent_growth_tree_concept_v1.png`

두 이미지 중 첫 번째를 **절대적인 그림체 기준**으로 사용하고, 두 번째는 완성 화면에서
가지가 붙는 방향과 밀도만 참고한다.

## ChatGPT 이미지 생성용 프롬프트

첨부한 첫 번째 이미지는 모바일 게임 `먹점프`의 영구 성장 화면에 사용하는 먹나무
중심 줄기입니다. 이 줄기에 이어 붙일 수 있는 **모듈형 수묵 나뭇가지 스프라이트
6종**을 만들어 주세요.

가장 중요한 조건은 여섯 이미지가 모두 첨부된 줄기와 정확히 같은 한 사람이 그린
것처럼 보여야 한다는 점입니다. 같은 검정·먹회색 농도, 같은 마른 붓결, 같은 거친
한지 번짐, 같은 어린 나무의 굵기 비율을 유지하세요. 고급 사실화나 정교한 동양
고화가 아니라, 단순하고 귀여운 모바일 캐주얼 게임용 한국 수묵화 스타일이어야 합니다.

각 가지는 별도 PNG 파일 한 장으로 만들고 다음 이름과 형태를 사용하세요.

1. `pg_branch_piece_01.png` — 완만하게 위로 휘는 기본 가지
2. `pg_branch_piece_02.png` — 완만하게 아래로 처졌다가 올라오는 S자 가지
3. `pg_branch_piece_03.png` — 짧고 굵은 직선형 연결 가지
4. `pg_branch_piece_04.png` — 끝부분이 두 갈래로 나뉘는 Y자 가지
5. `pg_branch_piece_05.png` — 주가지에서 짧은 곁가지 하나가 돋는 형태
6. `pg_branch_piece_06.png` — 특성 노드가 붙을 수 있게 끝이 가늘어지는 종결 가지

모든 파일의 제작 규격:

- 1024×1024 투명 PNG, 배경과 바닥 그림자 없음
- 가지는 화면 왼쪽 중앙에서 굵게 시작해 오른쪽 중앙에서 가늘게 끝남
- 시작점과 끝점의 세로 기준선을 여섯 파일 모두 동일하게 맞춤
- 가지가 캔버스 가로폭의 약 82~86%를 차지하고 사방에 충분한 투명 여백을 남김
- 게임에서 회전·확대·축소해 연결해도 접합부의 굵기와 먹 농도가 자연스럽게 이어짐
- 서로 겹치지 않은 독립 오브젝트 한 개만 표시
- 검정과 먹회색만 사용. 빨강, 금색, 초록, 꽃, 잎, 열매, 글자, 숫자, 문양 금지
- 외곽선만 그린 벡터 아이콘, 3D, 사진, 목탄, 유화, 서양 판타지 스타일 금지
- 가지 끝이나 붓결이 캔버스 경계에서 잘리지 않게 함
- 반투명 회색 배경을 만들지 말고 나뭇가지 픽셀 외 영역은 완전 투명 알파로 유지

먼저 6종의 스타일과 접합 규격을 동일하게 고정한 뒤, **한 번에 한 파일씩** 생성해
주세요. 첫 결과는 `pg_branch_piece_01.png`만 출력하고, 제가 승인하면 같은 세션의
스타일을 잠근 채 02부터 06까지 차례로 출력하세요. 이미지 안에는 파일명이나 설명
텍스트를 쓰지 마세요.

## Unity 연결 계약

완성 파일은 아래 폴더에 이름 그대로 넣는다.

`Assets/Resources/MukJump/UI/PermanentGrowth/`

코드는 `pg_branch_piece_01..06`을 계보와 노드 순서에 따라 선택한다. 아직 생성되지
않은 조각은 기존 `pg_branch.png`로 자동 대체되므로 한 장씩 검수하며 추가할 수 있다.
