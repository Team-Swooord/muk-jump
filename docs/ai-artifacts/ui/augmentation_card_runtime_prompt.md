# 먹점프 한 판 증강 카드 런타임 아이콘 프롬프트

## 공통 프롬프트

첨부한 세로 카드 이미지는 팔레트, 한지 질감, 한국 수묵담채의 붓결만 참고한다.
정사각형 모바일 게임 증강 아이콘 스프라이트 한 개를 만든다. 아이콘은 완전히 평평한
크로마키 녹색 `#00FF00` 배경 중앙에 고립시키고 그림자, 프레임, 글자, 숫자, 로고,
워터마크, 붉은색, 낙관, 태양, 캐릭터, 얼굴, 원형 장식, 마법 문양, 일본풍·중국풍
요소를 만들지 않는다.

한국 수묵화의 평면 2D 붓 표현으로, 어린아이가 그린 듯 친근하지만 완성도 있게 만든다.
검정 먹색 `#1C1B1A`, 숯빛, 탁한 청회색만 쓰며 `길운`에만 아주 작은 무광 금빛을
허용한다. 196px 모바일 UI에서도 읽히도록 2~3개의 큰 덩어리와 강한 실루엣만 사용한다.
피사체는 정사각형의 약 68% 안에 두고 모든 방향에 충분한 녹색 여백을 남긴다.
사진, 3D, 네온, 유광 음영, 강한 그라데이션, 복잡한 풍경은 금지한다.

## 증강별 중앙 상징

1. `먹두께`: 검정·숯빛·청회색의 넓고 둥근 먹층 세 겹. 방패·갑옷·캐릭터 금지.
2. `도약`: 위를 향해 힘차게 치솟는 검은 붓획 한 줄과 짧은 청회색 꼬리.
3. `큰 벼루`: 넓고 낮은 한국식 벼루와 넉넉한 청회색 먹물. 글자와 주변 도구 금지.
4. `먹샘`: 작은 돌 틈에서 솟는 먹방울 세 개와 부드러운 청회색 순환 획 하나.
5. `긴 여운`: 긴 검은 발판 획 하나와 뒤따르는 옅은 청회색 잔상 두 겹.
6. `겹친 획`: 서로 교차하지 않는 높이가 다른 굵은 평행 붓획 정확히 두 개.
7. `굳은 획`: 위로 살짝 휜 굵은 먹 발판이 위의 작은 각진 낙묵석을 막는 순간.
   충돌선은 짧은 두 개만 쓰고 방패·화살표·폭발은 금지한다.
8. `길운`: 글자 없는 단순한 한국 전통 복주머니에서 작은 먹방울 하나와 무광 금빛
   잎 하나가 피어나는 모습. 동전·붉은색·과한 술 장식은 금지한다.

## 후처리 규격

- ImageGen 출력 모드: `stylized-concept`, 카드 프레임을 스타일 레퍼런스로 첨부
- 녹색 배경 제거: border auto-key, soft matte, despill, edge contract 1px
- 아이콘: 피사체 알파 경계를 기준으로 잘라 최대 680px, 768×768 RGBA 중앙 정렬
- 카드 프레임: 512×1536 RGBA, 실제 프레임 영역 488×1520 중앙 정렬
- Unity: 아이콘 최대 512, 프레임 최대 1024, mipmap 없음, Clamp/Bilinear
