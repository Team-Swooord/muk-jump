사용하는 현재형 체크리스트다.

- `[x]` 코드·자동 검사로 확인

## 현재 출시 차단 요약

1. 먹점프 전용 AdMob 앱 ID·배너·보상형 단위와 UMP 메시지가 아직 없다.
2. 게스트·Apple·Google 로그인, 뒤끝 동기화, 계정 탈퇴, 서버 검증 리더보드가 아직 없다.
3. 개인정보처리방침·지원 URL과 스토어 데이터 공개 답변이 아직 확정되지 않았다.
4. Google Ads SDK 추가 이후 iOS 새 빌드와 Android AAB 실기기 검증이 필요하다.
5. 외부 폰트·오디오의 스토어 배포 및 공개 저장소 재배포 권리를 최종 확인해야 한다.
