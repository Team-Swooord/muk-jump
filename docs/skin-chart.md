# 스킨 엑셀과 뒤끝 차트

먹점프의 기본 먹 1개 + 해금 의상 61개를 한 시트에 담는다. 은퇴한 질풍 두건(ID 20)은 넣지 않으며 기존 ID와 계정 해금 기록은 유지한다.

## 수정·반영 순서

> **해금 곡선 v2 주의:** 현재 엑셀은 62행 × 26열이며 `unlockBalanceVersion=2`를 추가했다. 새 앱의 복합 해금 조건을 포함하므로 이전 앱을 대상으로 전역 적용하지 않는다. 이번 릴리스는 코드 기본값과 구 차트 자동 이관으로 동작하며, 새 엑셀의 서버 적용은 새 앱 출시 이후 호환 범위를 확인하고 수행한다.

1. `outputs/skin-chart-20260914/먹점프_스킨_뒤끝차트_v1.xlsx`의 노란 셀을 편집한다. 첫 행의 영문 열 이름, 시트 수, 행 ID는 유지한다.
2. 뒤끝 콘솔에서 **먹점프 → 차트 → MukJumpSkinsV1**에 수정한 파일을 업로드한다.
3. 새 파일을 선택하고 **차트 파일 적용**을 누른다. 업로드만 하거나 로컬 엑셀만 저장하면 게임에 적용되지 않는다.
4. 이 차트 연결 코드가 포함된 새 앱 빌드로 접속한다. 기존 배포 앱은 차트를 읽지 않으므로 연결 코드를 포함한 첫 배포가 한 번 필요하다.
5. 로그인 후 새 차트를 받아 첫 플레이 전 로비에서 적용한다. 이미 한 판이라도 시작했다면 받은 설정은 캐시에 보관하고 **다음 앱 실행**에 적용한다. 오프라인은 마지막 검증된 캐시, 캐시가 없으면 앱 기본 설정을 사용한다. 다운로드 중에도 튜토리얼과 플레이는 가능하다.

차트 식별자: `MukJumpSkinsV1`, 콘솔 차트 번호 `42720`. 초기 파일은 현재 게임과 같은 값이다. 다른 프로젝트·계정 정보·리더보드에는 쓰지 않는다.

## 참고한 던던던2 구현

`dungeondundeondungeon` 프로젝트의 `BackendManager.cs`(차트명 → 적용 파일 ID), `BaseChart.cs`(다운로드 → 초기화), `SkillChart.cs`와 `SkillData.cs`(행을 ID별 게임 데이터로 변환), `SkillData.csv`의 ID·설명·수치 열을 읽기 전용으로 확인했다. 공용 차트와 계정 저장을 분리하는 같은 구조를 사용한다. 던던던의 레거시 `Backend.Chart` 호출은 복사하지 않고 먹점프에 설치된 SDK의 `Backend.CDN.Content` API에 연결했다. 던던던 프로젝트·서버는 변경하지 않았다.

2026-09-14: 파일 `260525` 적용 확인. 콘솔에 표시된 62행 × 25열을 엑셀 원천 데이터와 공백 정규화 후 대조했으며 일치했다. 관련 검사 32개(차트 20 + HUD 12) 통과. 에디터의 실제 SDK CDN 조회는 시간 초과로 확인하지 못했으므로 실기기 다운로드 검증을 완료한 것으로 보지 않는다. 기존 배포 앱에는 아직 이 연결 코드가 없다.

## 엑셀 편집 범위

| 열 | 의미 / 편집 범위 |
| --- | --- |
| `nameKo`, `nameEn`, `nameJa` | 이름, 각 80자 이내. 한국어·영어·일본어를 함께 편집 |
| `loreKo`, `loreEn`, `loreJa` | 이름 아래 배경 이야기 |
| `unlockGoal` | `goalEditable=YES`인 일반 조건의 목표 숫자만 편집, 양의 정수 |
| `abilityNameKo/En/Ja` | 기존 특수 능력의 표시 이름 |
| `abilityDescriptionKo/En/Ja` | 기존 능력의 설명. 문장만 바꿔 새 능력이나 피해·도약 수치를 구현할 수는 없음 |
| `cooldownSeconds` | 바람부채·각시탈·거미탈만 1~600초. 실제 발동 간격·게임 HUD·능력 버튼에 공통 적용 |
| `schemaVersion`, `skinId`, `skinKey`, `tier`, `unlockMetric`, `abilityKey`, `unlockBalanceVersion` | 고정. 저장 호환성·실제 조건/능력 구현을 식별. 현재 해금 곡선 버전은 2 |
| `goalEditable`, `unlockRuleKo/En/Ja`, `assetKey` | 회색 참고 정보. 편집해도 게임에 사용하지 않음. 일반 조건 문구는 `unlockGoal`로 게임에서 자동 생성 |

쿨타임이 있는 능력 설명의 `{cooldown}`은 `cooldownSeconds` 값으로 바뀐다. 같은 한국어 문장이 여러 행에 있으면 번역도 같아야 한다. 새 능력 종류·스프라이트·스킨 추가, 복합 히든 조건 변경에는 코드/에셋 수정과 새 빌드가 필요하다. 기본 먹과 히든·연동·이벤트 조건의 목표 수치는 고정이다.

뒤끝 형식에 맞춰 한 시트만 사용하고 예약 열 `id`, 영문/숫자 이외의 열 이름, 역슬래시를 사용하지 않는다. 안내는 추가 시트/행 대신 열 머리글의 메모에 넣었다. [뒤끝 차트 공식 안내](https://docs.backnd.com/guide/console-guide/backnd-base/chart/).

## 안전 동작과 검증

- 정확히 62개 행을 한 번에 검사한다. 중복·은퇴·누락 ID, 틀린 스키마, 빈 번역, 범위 밖 숫자, 고정 조건 변경은 전체 파일을 거부한다. 부분 적용하지 않는다.
- 해금 비트나 유저 저장을 차트로 덮어쓰지 않는다. 이미 획득한 의상은 목표가 높아져도 유지된다. 아직 얻지 않은 일반 의상은 새 목표를 사용한다.
- 새 앱은 버전 열이 없는 구 차트/캐시에서 이전 기본 목표와 정확히 같은 값만 새 기본 목표로 이관한다. 별도로 편집한 수치는 유지한다. v2 차트의 명시적 목표는 그대로 사용하며 혼합/미지원 버전은 전체 거부한다.
- 기존 저장은 이미 보유한 의상과 이전 일반 조건을 충족한 실적을 보존한다. 용 사망 횟수는 새로 0부터 누적하되 기존 용꼬리 보유는 유지한다. 신규 계정에는 구 조건 보상이 적용되지 않는다.
- SDK CDN 목록에서 이름이 정확히 일치하는 차트 1개만 읽는다. 인증은 기존 계정 시스템을 사용하며 차트 조회 때문에 계정을 생성·삭제하지 않는다.
- 통신은 최대 3회, 회당 20초 대기로 제한한다. 조회 실패 시 게임을 막는 팝업이나 반복 토스트를 띄우지 않는다.
- 에디터에서는 자동으로 서버 설정을 덮어쓰지 않는다. `InkSkinChartTests`와 `InkSkinCooldownHudTests`가 해당 로직·HUD의 최소 회귀 검사다.
- WebGL은 현재 뒤끝 계정 시스템 범위 밖이므로 앱 내 기본 설정을 유지한다.

현재 코드 목록을 다시 뽑으려면 Unity의 `MukJump.EditorTools.InkSkinChartExport.ExportJson()`을 실행한 다음 같은 출력 폴더의 `build-workbook.mjs`를 사용한다. 이 내보내기는 기존 편집본을 덮어쓰므로 운영 중인 엑셀은 따로 보관한다. 런타임에서는 Excel 자체가 아니라 뒤끝에서 변환한 JSON을 읽는다.

해금 곡선만 동기화하려면 JSON 내보내기 후 `build-workbook.mjs --sync-unlock-curve`를 사용한다. 기존 이름·능력 설명·쿨타임 및 서식은 유지하고 목표, 조건 안내, 변경된 히든 힌트와 버전 열만 갱신한다.
