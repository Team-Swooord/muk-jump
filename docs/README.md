## 참고 자료와 역사 기록

- [프로젝트 브리핑](project-brief.md)은 외부 전달용 요약이다. 구현 판정의 단일 원본으로 쓰지 않는다.
- [2026-08-07 게임 바이블](MUKJUMP_MASTER_GAME_BIBLE.md)은 과거 스냅샷이며 현행 규칙이 아니다.
- 파일명에 날짜가 있는 audit/build/qa 보고서는 그 시점 증거다. 새 빌드 통과를 뜻하지 않는다.
- submission/의 공모전 자료, ai-artifacts/의 원화 프롬프트는 출처와 재현 목적으로 보존한다.
- THIRD_PARTY_NOTICES 및 언어별 개인정보 문서는 중복 삭제 대상이 아니다.

이 프로젝트 자체는 해당 로컬 보관함 없이도 위 상대 링크로 읽을 수 있다.
