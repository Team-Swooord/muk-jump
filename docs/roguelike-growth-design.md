# 먹점프 한 판 성장 설계

## 목표

`증강`은 로비의 먹방울 영구 성장과 별개로, 한 번의 도전에서만 드로잉
방식과 생존 전략을 바꾸는 로그라이크 선택이다. 최고 기록은 기존처럼 고도만 사용한다.
월드 획득 오브젝트와 내부 클래스명은 성장 두루마리를 유지하지만, 획득 뒤 선택
화면의 사용자 표시명은 `증강`으로 통일한다.

## 등장과 추첨

- 첫 두루마리: 45m
- 반복 간격: 120m
- 화면 활성 상한: 1개, 전용 단일 슬롯 풀 재사용
- 선택 수: 최대 단계가 아닌 성장 중 중복 없는 최대 3개
- 우선 구성: 모든 선택판에서 몸 1개 + 붓 1개를 먼저 보장하고 남은 전체 풀에서
  한 개를 보완한다. 로비 영구 성장은 후보 추첨에 개입하지 않는다.
- 난수: `GameplayRandomStream.Growth` 전용. 아이템·장애물 수열과 독립
- 후보가 1~2개만 남으면 빈 카드를 복제하지 않고 실제 개수만 중앙 정렬

현재 런타임 선택 풀은 아래 8종이다. 메인 도감에는
`RoguelikeGrowthCatalog`의 25계보×4노드, 정확히 100종이 표시되지만
`Planned` 92종은 효과 핸들러와 밸런스 테스트가 완성될 때까지 추첨하지 않는다.
계보·선행·상충·리롤/봉인 로드맵은
`docs/design/roguelike-growth-architecture.md`를 따른다.

## 증강 선택 UI

- 기준 해상도 `1080×1920`에서 두루마리는 `900×1480`, 선택 카드는
  `244×760`이며 최대 세 장의 중심을 X `-264 / 0 / 264`에 둬 20px 간격의
  가로 3열로 배치한다. 후보가 2개면 `-130 / 130`, 하나면 중앙에 둔다.
- 상단의 거친 먹원 안에 `증강`을 표시한다. 각 카드에는 큰 단색 성장 심벌 하나,
  옅은 담청회 먹달 하나만 두고 나머지는 한지 여백으로 남긴다. 카드 그림자·
  지면선·작은 별·점·점성술 선·서양 타로 문양·장식용 빨강은 사용하지 않는다.
- 선택 전에는 먹색·한지색·담청회색만 사용하며, 선택 확정 카드에만
  `InkPalette.Gold` 금빛 외곽선을 짧게 보여 준다.
- 선택 안내 34px, 카드 이름 40px, 단계 22px, 효과 28px, 하단 안내 24px을
  사용한다. 단계와 효과는 각각 한 줄로 제한한다. 전부
  `InkPalette.UiFont`, 합성 Bold와 얇은 먹 외곽선을 적용해 인게임 HUD와 같은
  대비를 유지한다.
- 카드 안에서는 이름·단계·효과 영역 사이를 각각 최소 8px 띄운다. 효과는
  `점프력 +4%`처럼 핵심 수치만 남긴다. 글자를 자동
  축소하지 않고 텍스트 영역과 카드 자체를 함께 키운다.
- `CanvasScaler`의 높이 기준 논리 Safe Area가 두루마리보다 좁을 때만 전체를 균등
  축소한다. 개별 글자나 카드만 줄이지 않아 정보 위계와 터치 영역 비율을 보존한다.
- 펼침 0.26초, 닫힘 0.16초는 유지한다. 자주 보는 선택창이므로 추가 장식 애니메이션은
  넣지 않고 첫 프레임부터 뒤 게임 입력을 차단한다.

## 성장 풀

| 성장 | 단계당 효과 | 최대 단계 | 최대 효과 |
|---|---:|---:|---:|
| 먹두께 | 먹떼 공용 장애물 완충 +1 | 3 | 3회 |
| 도약 | 일반 자동 점프력 +4% | 5 | +20% |
| 큰 벼루 | 최대 먹 +10% | 4 | +40% |
| 먹샘 | 먹 회복 +12% | 4 | +48% |
| 긴 여운 | 임시 발판 수명 +10% | 3 | +30% |
| 겹친 획 | 동시 임시 발판 +1 | 1 | 4→5개 |
| 굳은 획 | 새 임시 발판마다 낙묵석 1회 방어 | 1 | 발판별 1회 |
| 길운 | 다음 일반 아이템 간격 -7% | 3 | -21% |

먹두께는 분신별 체력으로 복제하지 않는다. 추락에는 적용하지 않고 개별 방어막을
먼저 소비한다. 도약은 먹물방울 50m 상승과 풍맥 상승에 적용하지 않는다.

긴 여운은 먹비 구간의 `0.72` 수명 배율을 지우지 않고 곱한다. 최대 성장에서도
`0.72 × 1.30 = 0.936`이므로 먹비 구간은 평소보다 짧다. 겹친 획은 모바일
LineRenderer·Collider 예산을 고려해 한 단계만 허용한다. 길운은 이미 보이는
아이템을 순간이동시키지 않고 다음 스폰 간격부터 적용한다.

## 범용 아이콘 규칙

이미지에는 수치, `+`, 레벨, 카드 프레임을 넣지 않는다. 투명 단일 심벌이므로 성장
카드, 디버그 패널, HUD 요약, 월드 픽업에 같은 파일을 재사용할 수 있다.
장식용 붉은 점·낙관은 반복 사용하지 않는다. 붉은색은 `굳은 획`의 위험물처럼
게임 규칙을 구분할 필요가 있을 때만 쓰고, 나머지는 먹색·회색·한지색으로 제한한다.

| 파일 | 의미 | 재사용 |
|---|---|---|
| `growth_vitality.png` | 생존·완충 | 먹두께 |
| `growth_jump.png` | 상승·이동 | 도약 |
| `growth_ink_capacity.png` | 자원 그릇·용량 | 큰 벼루 및 향후 자원 상한 |
| `growth_ink_regen.png` | 회복·재생 | 먹샘 및 향후 회복 효과 |
| `growth_platform.png` | 여러 획·발판 | 긴 여운, 겹친 획 공용 |
| `growth_guard.png` | 획이 위험물을 막음 | 굳은 획 및 향후 발판 방어 |
| `growth_fortune.png` | 발견·행운 | 길운 및 향후 보상 계열 |

원본 PNG는 1024px 이상으로 보관하되 Unity 런타임 임포트는 최대 512px,
MipMap 비활성, `CompressedHQ`를 사용한다.

## 세션 경계

선택 단계, 먹두께 잔여 충전, 먹 용량 증가, 먹 여유, 황금 붓 시간은 새 도전에서
초기화된다. 직렬화된 기본 밸런스 값을 직접 덮어쓰지 않고 모든 성장 효과를 조회형
배율로 계산해, 구간 전환이나 재도전에서 중첩되지 않게 한다.
