# 로그인·뒤끝·동기화 점검 — 2026-09-10

## 현재 결론

사용자 제보의 43m는 실제 먹점프 뒤끝 `MukJumpPlayer` 행에 있으며 완료 판 이력도 있다.
그러나 실제 리더보드는 비어 있다. 로컬 기록 손실과 순위 등록 실패는 다른 문제다.
리더보드 UUID, 테이블, `bestHeight` 설정 일치는 콘솔에서 확인했다.
실패한 휴대폰 API 응답을 아직 확보하지 못했으므로 이 증상의 단일 원인을 확정하지 않는다.
테스트 계정/43m 기록은 삭제하지 않았다. 이번 변경은 아직 TestFlight에 반영되지 않았다.

## 수정 및 검증 범위

| 경로 | 검증/수정 |
|---|---|
| 게스트 기록 → Apple 연동 → 순위 | 검증한 서버 저장의 소유자별 제출 예약을 잠금 전 보존. 43m 재시도 테스트 |
| 미플레이 계정 → 로그인 | 완료 판이 없으면 0m 포함 순위 제출 금지. 실제 완료한 0m는 허용 |
| UID 수신 → 닉네임 조회 실패 | UID가 있어도 사용자 정보 재조회. 로비에서도 제한된 간격으로 복구 |
| 게스트 자동 이름 → 서버 저장 실패 | 이미 사용자 정보를 읽었더라도 자동 이름 생성 재시도 |
| 계정 제공자 확인 중 → 이름 변경 | 인증 전환 중 변경 차단. 성장 데이터 형식 오류만으로 별도 이름 변경을 막지는 않음 |
| 전환/로그아웃/탈퇴 정리 중 → 저장 | 일반 저장도 계정 잠금 준수. dirty와 로컬 원본 유지 |
| 저장 성공 → 응답 유실 → 재시도 | 직전 요청 ID와 다음 revision이 같은 경우만 자기 저장으로 확인. 추가 로컬 변경 보존 |
| 다른 요청/다른 서버 세대 | 자동 덮어쓰기 금지 및 기존 충돌 선택 유지 |
| 순위 쓰기 중 → 클라우드 조회 | 요청을 버리지 않고 같은 소유자로 직렬화 |
| 저장 후 로그아웃 → timeout | 같은 계정의 재시도 동안 로그아웃 의도 유지. 실제 세대/계정 변경에는 폐기 |
| 인증/읽기/쓰기의 늦은 응답 | 기존 세대/소유자 검사와 watchdog 회귀 검사 |
| 로그아웃/탈퇴 실패 → 재시작 | 기존 복구 표식, 소유자 격리, 로컬 삭제 실패/취소 회귀 검사 |
| 튜토리얼·성장·최고 점수 복구 | 기존 첫 실행/성장/계정 교체 및 저장 실패 회귀 검사 |

## 자동 검사

- 추가 재현 테스트는 실제 서버 호출을 대체한 SDK 응답과 지연/실패를 사용한다.
- 초기 추가 12개 검사에서 수정 전 실패를 확인했다. 기존 독립 닉네임 변경 계약을
  침해하지 않도록 잠금 범위를 조정하고 후속 회귀 검사를 추가했다.
- 계정·이름·첫 안내·성장 저장·뒤끝 빌드 설정 확장 검사: 최초 561/561 통과.
- 전체 실행에서 계정 349, 이름 99, 첫 안내 17, 성장 저장 91, 뒤끝 설정 6:
  관련 562/562 통과. 설정창 검사도 같은 전체 실행에서 135/135 통과했다.
- 전체 게임 검사 1,934개: 1,932 통과, 1 실패, 1 제외. 실패는
  `GrowthTweenCompletesAndCancelsInRealPlayAtZeroTimeScale`의 위치 정확 비교다.
  제외는 수동 실행용 `RenderIsolatedLeaderboardWithoutNetworkOrSceneWrites`다.
- 일반/다크 각각 10구간 실제 Unity Play 검사 통과. 기본 7맵과 무한 구간 반전 순환,
  그리기/아이템/바람/일시정지/취소/재개/사망/결과/로비 재로드를 포함한다.
- 앞선 개별 설정창 실행에서는 글자 높이 관련 4개 실패가 있었으나 전체 실행에서는 통과했다.
  검사 순서/환경에 따른 차이는 UI 검사 안정성의 후속 확인 항목이며 UI 수정 완료로 보지 않는다.
- 자동 테스트 통과는 Apple 네이티브 인증이나 실제 서버 왕복 성공의 증거가 아니다.

마지막 수정(인증 전환 중 자동 이름 조회 제한, 한/영 복구 안내)을 포함한 관련 재검사:
계정/이름/첫 안내/성장 저장/뒤끝 설정/영어 번역 **605/605 통과**, C# 컴파일 오류 없음.
성장 위치 비교 실패는 별도 재실행에서도 재현됐고 이번 계정 수정 범위에서 변경하지 않았다.

검증 원본 보관: `output/release-qa/account-sync-2026-09-10/`의 전체/최종 관련 검사 XML 및 로그.

## 실기기 완료 조건 — 아직 미완료

1. 연결 가능한 아이폰에서 게스트 43m 저장 → Apple 연동 → 동일 UID 소유자 확인.
2. 서버 행 43m, 실제 리더보드 43m, 앱 순위 43m 세 위치 일치.

검증을 대체하지 않는다. 실기기 왕복 완료 전에는 출시 점검 완료로 표기하지 않는다.
