# 먹점프 (Ink Jump)

> "선 하나가 발판이 되고, 발판 하나가 그림이 된다"

NHN NAN 2026 · Game × AI Hackathon 제출작 — Team-Swooord

동양화(수묵화) 감성의 드로잉 클라이밍 게임입니다. 캐릭터 **먹방울이**는 일정 주기마다
스스로 점프하고, 플레이어는 화면에 손가락으로 선을 그어 발판을 만들어 점프의
방향과 높이를 유도합니다. AI로 탐색·제작한 수묵 아트 방향을 런타임의 로컬 갈필
스타일러가 즉시 적용해, 네트워크 없이도 화면 전체가 하나의 산수화처럼 유지됩니다.

## 게임 방법

| 항목 | 내용 |
|---|---|
| 목표 | 발판을 그려 먹방울이를 최대한 높이 올려 보내기 (최고 고도 = 점수) |
| 조작 | 화면 하단 여백(한지 영역)에 손가락으로 선을 긋기 → 발판 생성 |
| 점프 | 첫 점프는 접지 후 충전, 이후에는 정점부터 다음 점프를 충전해 착지 시 자동 점프 |
| 발판 | 일반 먹색·풍맥 청회색으로 효과를 구분하며, 대각선 발판에도 붙을 수 있음 |
| 발판 수명 | 그린 선은 생성 후 총 약 4.5초 유지되며 마지막 0.8초 동안 먹이 마르듯 사라짐. 동시에 최대 4개 유지 |
| 먹 자원 | 기본 12, 초당 3.0 회복. 그리는 중에는 회복하지 않음 |
| 아이템 | 첫 12m 먹분신 보장, 먹물방울 50m 점프, 황금 붓 8초 무한 먹, 방어막 1회 보호, 붓 여유 +35% |
| 생존 | 분신 아이템 하나마다 캐릭터가 정확히 1마리 늘어나며 최대 24마리. 한 마리라도 살면 계속 진행 |
| 장애물 | 30m까지 안전 구간. 이후 이동 먹가시·낙묵석, 60m부터 4프레임으로 통통 움직이는 어린이 낙서풍 동양 용이 좌우 이동 |
| 구간 | 0·250·500·750m 기본 산수화 이후 1000m부터 먹빛 성문·월련 성해·천하수 우주 수채화가 무한 순환 |
| 날씨 | 먹선·한지 풍향 HUD가 가리키는 방향으로 약한 횡풍이 불고, 수백 m마다 강한 상승기류가 낙하를 잠시 막음 |
| 피드백 | 플레이 중 신기록 낙관, 아이템 등장 예고, 강한 점프 카메라 펄스, 충돌 순간 정지, 진동, 적의 붉은 한지색 본체 |
| 일시정지 | 우측 상단 쉼 버튼 → 현재 도전을 보존하고 계속하거나 붓 전환 뒤 로비로 복귀 |
| 음악 | Suno로 제작한 국악풍 `Inkdrop Ascent`를 상태별 음량 페이드와 함께 반복 재생 |
| 종료 | 화면 아래로 추락하거나 장애물에 맞으면 먹 자국을 남기고 사망 → 터치 재도전 |

## 실행 방법

### APK (제출 빌드)

Android 기기에서 APK 설치 후 바로 실행. 별도 계정·유료 라이선스 불필요.
발판의 수묵 변환은 로컬 절차적 스타일러만 사용하므로 네트워크·API 키가 필요 없습니다.

### 에디터에서 실행 (소스 빌드)

1. Unity **6000.3.10f1** (URP) 설치
2. 이 저장소를 클론 후 Unity Hub에서 프로젝트 열기
3. 최초 1회: 메뉴 `MukJump > Build Main Scene` 실행 → `Assets/Scenes/Main.unity` 생성
4. `Main.unity` 씬을 열고 Play — Game 뷰를 세로(9:16) 비율로 설정

### 개발용 디버그 패널

플레이 중 화면 왼쪽 `DEBUG` 버튼을 누르면 아이템 5종을 즉시 적용할 수 있다.
`무적 ON`에서는 장애물 충돌 시 반동하고 화면 아래로 떨어지면 다시 상승한다.
산길 0m·바람 250m·먹비 500m·협곡 750m 버튼으로 맵 전환 지점에 즉시 이동하고,
풍향 전환·상승기류 테스트와 풍맥 발판 생성을 즉시 실행할 수 있다. 풍맥 발판은 아래에서
위로 통과할 수 있고, 위에 착지한 캐릭터마다 한 번씩 빠른 상승을 제공한다.
제출 플레이에서는 패널을 닫아 두며, 닫힌 패널은 드로잉 입력을 가로채지 않는다.

## 프로젝트 구조

```
Assets/
  Art/                캐릭터·기본 고도 맵 배경 4종·UI 원본 (PNG)
  Resources/          1000m 이후 무한 우주 수채화 배경 3종
  MukJump/VFX/        Codex로 생성한 자체 VFX·SFX
  Scripts/
    Core/             GameManager, ScoreManager, CameraFollow, 공용 Pooling 계약
    Player/           AutoJump, PlayerController, 화면 경계
    Drawing/          StrokeCapture, BezierSmoother, PlatformCollider
    Items/            아이템 스폰·획득·효과와 기능 전용 풀
    Obstacles/        이동 장애물·낙묵석과 기능 전용 풀
    AI/               SketchToInkService(로컬 수묵 스타일), FallbackInkStyle
  Scenes/Main.unity   메인 씬
docs/ai-usage-log.md  AI 활용 내역 (제출물 4번 원본 자료)
docs/architecture.md  기능 경계·풀링·발판 충돌 정책
docs/code-audit-2026-07-26.md 제출 전 코드·보안·라이선스 감사 결과
docs/project-brief.md 프로젝트 기획과 현재 구현 상태를 정리한 전달용 브리핑
```

반복 생성되는 아이템·장애물·낙묵석·짧은 피드백·먹물점프 합성 연출은 기능별 지연 풀로
재사용한다. 먹물점프 합성 풀은 모든 분신이 게임 전체 3묶음을, 황금 붓 표현은 24개
렌더러 한 묶음을 공유한다. 결과창, 전환 UI, 아이템 효과, 전역 바람선과 구간 날씨선은
실제로 필요할 때 처음 생성한다.
이동 먹가시와 어린 용은 같은 고도 예약과 풀을 공유해 서로 겹쳐 생성되지 않는다.
어린 용은 렌더러만 4프레임으로 교체하며, 풀 반납 때 애니메이션 상태를 초기화하고
충돌 판정은 프레임 여백과 무관하게 같은 크기로 유지한다.
대량 분신에서는 카메라와 위험물 해금이 먹떼의 하위 중앙값을 따라 소수 선두의
먹물방울 부스트로 인한 연쇄 추락·조기 난도 상승을 막고, 분신 방어막 입자와 같은
프레임의 사망 피드백을 축소·병합한다.
세부 의존 방향과 생명주기는 `docs/architecture.md`에 고정한다.

상단 HUD는 한 장의 한지 붓획 안에 풍향·`고도 4m`·`최고 494m`를 굵은 한 줄씩
3열로 표시한다. 10,000m부터는 `10km` 단위로 압축해 숫자가 길어져도 잘리지 않는다.
현재 고도가 도전 시작 시점의 최고 기록을 처음 넘어서는 순간 최고 기록 숫자가 붉게
바뀌고 작은 `신` 낙관이 찍혀 해당 플레이가 끝날 때까지 유지된다. 풍향은 보통
28~45초 동안 같은 방향을 유지한 뒤 먹선이 흐르듯 천천히 전환하며, 강풍 예고·
상승기류·회복 중에는 방향 유지 시간이 흐르지 않는다.
주요 수치·상태 문구·결과창은 작은 화면에서도 읽히도록 굵기·크기·먹색 대비를 높였고,
일시정지판은 Safe Area 안의 큰 `계속하기`·`로비로` 버튼으로 구성한다.
