# 남은 사건 VFX — 순차 구현 규격

기준: Unity 6000.5.9f1 / 기존 URP 2D / 씬·물리·경제 변경 없음.
`docs/VFX/SKILL.md`의 의미→시간차→고정 풀→품질별 축소 순서를 적용한다.

## 2. 50m 상승

- 의미: 일반 점프와 달리 강한 먹 분출로 위로 솟는다.
- World: 출발점 먹 튐, 현재 선두 뒤 최대 몸높이 7배의 붓 꼬리.
- 0~0.28초: 기존 blob/splash/ring. spray는 굵은 방울(0.09~0.16배)과 가는 획(0.035~0.065배)을 분리.
- 0.08~0.26초: 잔상 1/2/3장, 각각 0.28초 감쇠. 잔여 방울은 현재 꼬리에서 방출.
- 0.65~1.8초: 기둥 알파 0.72→0, 2.1초에 풀 반납.
- 기존 52자식/합성 풀 1·2·3묶음 유지. 독립 xorshift 난수. Reduced는 분사·잔상 없이 짧은 핵심만.
- 검증: 풀 반복, High→Low, 재생 중 Reduced, 난수 독립, 50m 위치의 꼬리 상한, 실제 4등급 촬영.

## 3. 방어막·아이템

- 의미: 획득은 바깥 먹이 모임, 소모는 이미 생긴 고리가 깨짐.
- 0~0.42초 획득: 1.7배 고리→보유 고리, 기존 motes 응집. 완료 때 초과 입자 감쇠.
- 보유: 기존 고리와 본체 최대5/분신2 알갱이. 품질 변경에도 고정 slot 각도.
- 소모: 외곽에서 0.7초 갈라지는 파편. 부모 계층은 유지하되 월드 위치 적분으로 캐릭터 상승을 따라가지 않음.
- 기존 본체11/18·분신4/6 캐시 재사용. 파편 시각 난수 독립, Reduced 즉시 입자 제거, OnDisable 모든 임시 상태 초기화.
- 황금 붓은 기존 게이지 색 변화만 유지. 획득 아이콘 수렴·흡수와 아이템별 signature를 보존.

## 4. 유효 먹선·분신

- 의미: 유효 획은 붓끝 섬유가 정착, 분신은 흩어진 먹이 짧게 몸통으로 모임.
- 씬의 기존 `InkContactParticles` 세 시스템·두 재질·37/62/90 총 상한을 공유하며 시스템을 추가하지 않음.
- 유효 끝점: 0.28~0.5초 작은 갈필 4/6/8개 + 먹방울 1/1/2개. 먹 정산·콜라이더 생성은 즉시 유지.
- 분신: 0.18~0.24초 안쪽 응집(4/6/8개)에 초기 본체 이동 속도를 전달한다. 0.12초 몸통→0.18초 본체 팝 유지. Reduced는 본체 즉시 표시, 장식 없음.
- 폴백 유지. 반복 24개에도 하드 예산 준수. 입자가 게임 난수·입력·충돌에 영향 없음.

## 5. 피격·사망·위험

- 기존 본체 8프레임 사망·먹 자국·체력 flash/tail·위험 낙관을 보존한다.
- 중복 폭발을 새로 추가하지 않는다. 장식 포화 시 Critical 예약, 일시정지 복원, 사망 강제 피드백을 회귀 확인한다.
- 실제 촬영에서 낙묵석 낙관이 먹 게이지에 가리는 문제를 확인하여 HUD의 실제 위쪽 경계+16px 이상 여백으로 올린다. 최대 고리 반경과 선 두께를 포함하며 X·0.9초 예고·충돌은 유지한다. 3종 Safe Area 위치 계산과 현재 Editor 렌더 경로를 각각 검사하며 이를 실기 검증으로 표현하지 않는다.
- 기능/Editor 실제 프레임 증거와 실기기 성능 승인은 분리한다. Android/iOS 열·GPU·30분 soak는 기기에서 별도 검증.
