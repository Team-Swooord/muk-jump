# DOTween 1.3.030

공식 배포본: https://dotween.demigiant.com/downloads/DOTween_1_3_030.zip
라이선스: https://dotween.demigiant.com/license.php

수정하지 않은 코어 DLL, XML 문서, 원본 readme와 공식 런타임 Modules를 포함한다. 에디터 도구는 설치하지 않았다.
성장 UGUI 연출은 코어의 `DOTween.To` / `Sequence`를 사용한다. 코어가 초기화 시 참조하는 `DOTweenModuleUtils`를 포함하여 런타임 모듈 시스템을 유지한다.
현재 연출의 Sequence만 종료 시 Kill하며 전역 KillAll이나 전역 설정 변경은 하지 않는다.
라이선스상 외부 배포 시 원본 고지와 readme를 유지하고 DOTween 자체의 수정본을 재배포하지 않는다.
